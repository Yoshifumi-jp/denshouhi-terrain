## 2. 試しの判定（徳島の碑 71基の全件、ズーム16、通信エラー0）

### 人工地形
- 人工地形の範囲の中：**12基**（すべて code 11014＝盛土地・埋立地）。例：36383-001 牟岐大震潮記念碑、36383-010 南海地震津波最高潮位、36402-002 北島町大正の大洪水、36401-001 敬渝碑（自然地形は旧水部）
- タイルはあるが人工地形の外：36基／タイルなし（404）：23基
- 詳細版（自然地形）が「データなし」の11基は、すべて人工地形もタイルなし。人工地形の12基はすべて詳細版で値ありの碑 → **人工地形は詳細版と同じ範囲にだけある**（推測ですが、同じ土地条件調査が元のため）
- 決めておくべき扱い：タイルなし（404）は「人工地形なし」か「調べていない範囲」か区別できない。詳細版の値がある地点の404は「人工地形なし」、詳細版データなしの地点は「範囲外」とする案
- 取得量の見込み：自然地形 ZL16 のキャッシュが2,208枚 → 人工地形も同程度（推測で40〜50分）

### 治水地形分類図
- タイルがあったのは **71基中18基**（国が管理する河川の流域だけ。牟岐・海陽など海沿いの碑の多くは範囲外）
- 18基の画素の色は16種類。白（255,255,255）・灰（90,90,90 など線や文字と思われる色）が混じり、凡例の色と1対1に対応しない
- 旧河道・自然堤防・氾濫平野などは、今の自然地形（詳細版）にすでに入っている（全国で旧河道56基・自然堤防172基）。重なる部分が大きいと推測

## 3. 見通し（Claude の判断）
- 人工地形：今の仕組みと同じ作り方で足せる。第3版（地域版）と同じ進め方（別ファイル・既存は不変）で修正ループが少ないと見込む
- 治水地形分類図：色の読み取りは、線・文字・模様・ぼかしで誤判定しやすく、範囲も限られる。自然地形との重なりも大きい。第4版から外し、必要なら第5版以降で「色の判定の正解づくり」から別に検討するのがよい

## 4. 全国の抜き取り調査（Claude 2026-10-18、本人依頼）
- 方法：全国の碑2,481基から無作為に150基（乱数の種 20261018）。人工地形 ZL16 で判定。通信エラー0
- 結果：
  - 人工地形の範囲の中：**21基（150基の14%）**。詳細版で値のある98基に限ると21%
    - 盛土地・埋立地 15基（code 11014 7・11006 6・4010201 2）
    - 干拓地 6基（code 4010101 5・11008 1）
  - 詳細版で値あり・人工地形の外 77基（タイルはあるが外 43、タイルなし 34）
  - 詳細版データなしの52基は、すべてタイルなし（徳島と同じ傾向）
- 例：41208-004・23100-008・43206-011・24344-002（自然地形 旧水部 × 干拓地）、13107-003・11238-001（氾濫平野 × 盛土地・埋立地）、04202-008（氾濫平野 × 盛土地・埋立地）
- 全国の見込み（推測）：14%×2,481＝約350基（抜き取りのぶれを考えると、およそ220〜500基）
- 気づいたこと：干拓地の6基のうち5基は自然地形が「旧水部」。「もとは海・湖を干拓した土地」が自然地形と組み合わせて読める
