## 目的（このテーマ1つ）
河川・海岸線のシェープファイルに「点が1つしかない線」が含まれていても、その線だけを除いて読み込めるようにする。

## （修正）不具合の内容
- 起きていること：M12 の4回目（2026-10-10）で、岐阜（21）と愛知（23）が「[3/14] 河川・海岸の付与（碑）」で失敗した。画面の表示は
  `エラー: 河川ファイルの読み込みに失敗しました: IllegalArgumentException: point array must contain 0 or >1 elements`
- 原因（Claude が確認済み）：両県の隣接県である三重（24）の河川データ `data/raw/rivers/W05-08_24_GML/W05-08_24-g_Stream.shp` の 7,527本のうち1本が、点が1つしかない線（形として不正）。`read_line_shapefile`（src/add_river_coast.py 127行付近）の `gpd.read_file` が、この1本のために全体の読み込みを止める
  - 該当の線：先頭から 3,880 本目（0始まりで 3879）、W05_004（河川名）＝「堀の谷」、W05_002（河川コード）＝ 8505130000、点 (136.33546513, 34.36848217)
  - 河川47・海岸線39 の全ファイルを調べ、不正な線はこの1本だけ
- 本来の動き：不正な線だけを除き、残り 7,526本で計算を続ける。除いたことは画面に1行で知らせる
- 影響：このままでは三重を河川の読み込みに含む県（21 岐阜・23 愛知・24 三重・25 滋賀・26 京都・29 奈良・30 和歌山）がすべて失敗する（5・6回目の実行前に直す必要がある）

## やること
1. src/add_river_coast.py の `read_line_shapefile` を次の動きにする
   - `gpd.read_file(shp_path, encoding="cp932", on_invalid="ignore")` で読む（`on_invalid="ignore"` は、不正な形の行をジオメトリなし（None）として読む pyogrio の設定。geopandas 1.2.0・pyogrio 0.13.0 で動くことを Claude が確認済み）
   - ジオメトリが None または空の行を除く
   - 除いた行が1行以上あるときだけ、次の1行を表示する（0行のときは何も表示しない。他の県の表示を変えないため）
     `注意: <ファイル名> に形の壊れた線が <件数> 本あったため、除いて読み込みます`
     （<ファイル名> は `shp_path.name`。例：`注意: W05-08_24-g_Stream.shp に形の壊れた線が 1 本あったため、除いて読み込みます`）
   - その後の `set_crs("EPSG:4612", inplace=True)` と戻り値は今のまま
   - 関数に、なぜこの処理があるかを日本語のコメントで書く（三重の河川データの例）
2. tests/test_add_river_coast.py に実データのテストを1つ追加する（test_read_line_shapefile_skips_broken_line など）
   - 三重のファイル `data/raw/rivers/W05-08_24_GML/W05-08_24-g_Stream.shp` が無いときは `pytest.skip`（data/raw は Git で管理していないため）
   - あるときは、`read_line_shapefile` の戻り値が 7,526 行で、ジオメトリの None・空が0件、W05_004 が「堀の谷」かつ W05_002 が 8505130000 の行が0件であること、表示（capsys）に上の「注意:」の1行が1回だけ出ることを確かめる
   - 既存のテストでは「注意:」が出ないこと（既存のテストは変えない）
