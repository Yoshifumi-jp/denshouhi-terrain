## 目的（このテーマ1つ）
県の境に近い碑のために、河川・海岸線までの距離を「対象県＋陸で接する隣接県」のデータで測る。
足りないデータがあれば一覧を出して止まる。海のない8県は海岸までの距離を「対象外（海のない県）」にする。
GitHub への push・git commit は行わない。

- 変えないもの：ほかの src/*.py（summarize.py・make_map.py などは「取得済」以外の海岸を集計から外し、地図では状態の文をそのまま出す作りのため、変更不要）、data/ の中（6章で作り直してから元に戻すものを除く）

## 1. src/prefectures.py（追加）
1. `NEIGHBORS`：県コード → 陸で接する県コードのリスト（小さい順）。47県すべてを書く。中身は docs/dev/m10_neighbors.md の表のとおり（87組）。表の作り方・照合メモを2〜3行のコメントで書く
2. `LANDLOCKED`：海のない8県の frozenset：`{"09", "10", "11", "19", "20", "21", "25", "29"}`（栃木・群馬・埼玉・山梨・長野・岐阜・滋賀・奈良）

## 2. src/add_river_coast.py（変更）
1. 新しい関数 `find_input_shapefiles(pref_code, raw_dir)` → `(河川のパスのリスト, 海岸線のパスのリスト, 足りないもののリスト)`
   - 対象の県＝`[pref_code] + NEIGHBORS[pref_code]`（この順）
   - 河川：対象の県それぞれについて `raw_dir / "rivers"` で `W05-*_{県}_GML/*_Stream.shp` を今の `find_shapefile` で探す
   - 海岸線：`pref_code` が LANDLOCKED のときは**探さない**（空のリスト）。それ以外は、対象の県のうち LANDLOCKED でない県について `raw_dir / "coastline"` で `C23-*_{県}_GML/*_Coastline.shp` を探す
   - 見つからないものは「足りないもののリスト」に `f"河川 {県名}（{県}）: data/raw/rivers/W05-*_{県}_GML/*_Stream.shp"`（海岸線は `f"海岸線 {県名}（{県}）: data/raw/coastline/C23-*_{県}_GML/*_Coastline.shp"`）の文字列で入れる。対象の県の順、河川→海岸線の順
2. `process_river_coast` の変更
   - `rivers_shp`・`coast_shp` は、パス1つ（今までどおり）か**パスのリスト**を受け付ける。リストのときは、それぞれ `read_line_shapefile` で読み、`pd.concat(..., ignore_index=True)` で1つにしてから（座標系は EPSG:4612 のまま）今の処理に渡す。`coast_shp` が None・空のリストのときは今までどおり「データなし」
   - 引数の最後に `no_sea=False` を追加。True のときは海岸線を読まず、全件の `海岸_状態` を `"対象外（海のない県）"`、`海岸までの距離_m` を空欄にする（「データなし」の件数には数えない）。1件ごとの表示は `海岸 対象外`
   - まとめ表示：「海岸「データなし」の件数: …」の直後に `海岸「対象外（海のない県）」の件数: {件数}` を足す
3. `main()` の変更
   - 河川・海岸線を探す部分を `find_input_shapefiles(pref_code, PROJECT_ROOT / "data" / "raw")` に置き換える
   - 足りないものが1つでもあれば、次を出してコード1で終了する（処理は始めない）
     ```
     次のデータが足りません。国土数値情報からダウンロード・展開して data/raw/ に置き、もう一度実行してください:
       河川 香川県（37）: data/raw/rivers/W05-*_37_GML/*_Stream.shp
     ```
   - 今の「海岸線ファイルが見つかりません。全件の海岸を「データなし」として処理します。」の動きはやめる（足りないものとして止まる）
   - 処理の前に次の2行を出す（県名と県コード、対象の県の順。海のない県の海岸線は「なし（海のない県）」）
     ```
     読み込む河川データ: 徳島県（36）、香川県（37）、愛媛県（38）、高知県（39）
     読み込む海岸線データ: 徳島県（36）、香川県（37）、愛媛県（38）、高知県（39）
     ```
   - `process_river_coast` に河川・海岸線のリストと `no_sea=(pref_code in LANDLOCKED)` を渡す
4. 河川コード（W05_002）が隣接県のデータと重なる（県境をまたぐ川が両方の県のデータに入っている）ことがあるが、距離が最も近い線を選ぶだけなので、重複は取り除かなくてよい
