## 目的（このテーマ1つ）
県別の表示（地図のポップアップと県別ページ）に、地形分類の地域版を反映する。
表示の決まり（計画書 版12）：**詳細版があれば詳細版、なければ地域版（「地域版」と明記）**。詳細版と地域版を混ぜて集計はしない。

## 対象ファイル
- src/make_map.py（変更）
- src/build_site.py（変更）
- tests/test_make_map.py（テスト関数を3つ追加。既存のテストは変えない）
- tests/test_build_site.py（テスト関数を1つ追加。既存のテストは変えない）

## やること（手順）

### 1. make_map.py：地域版の読み込み
1. `load_data(pref)` で、碑の表に `data/processed/landform_region_{pref}.csv` を ID で左結合する。使う列は `ID`・`地域版_地形分類名`・`地域版_状態` の3列だけ（碑名・緯度・経度・取得日などは結合しない）。
2. このファイルが無いときは止めずに、次の1行を表示して続ける（地域版の列は無いものとして扱う）：
   `地域版のファイルがありません（landform_region_{pref}.csv）。地形分類は詳細版だけを表示します`
   ※ {pref} は県コード（例 36）に置き換える。

### 2. make_map.py：ポップアップの「地形分類」の行
`build_popup_html` の地形分類の文（lf_text）を次の決まりにする。行の見出し「地形分類：」は変えない。行を増やさない。
| 詳細版（地形分類_状態） | 地域版（地域版_状態） | 表示 |
|---|---|---|
| 取得済（今と同じ条件：コードが空でない） | 何でも | 詳細版の分類名（今と同じ） |
| それ以外 | 取得済（地域版） | `<地域版_地形分類名>（地域版）` 例：`山地（地域版）` |
| それ以外 | 取得済（広域版） | `<地域版_地形分類名>（広域版）` |
| それ以外 | それ以外・列が無い・空 | `データなし`（今と同じ） |
- 分類名は今と同じく html エスケープする。
- 関数の引数は増やさない（row の列から判定する）。row に地域版の列が無いときは今とまったく同じ結果になること（既存のテストがそのまま通ること）。

### 3. make_map.py：凡例の「出典・ご利用上の注意」に1行
「地形分類：国土地理院 地形分類（自然地形）」の行の直後に、次の1行（li）を足す：
`地形分類で「（地域版）」と付いたものは、詳細版のデータがない所を地域版（中分類）で補ったものです。地域版は分類が粗く、詳細版とは細かさが違います。`

### 4. make_map.py：実行時のまとめ表示に2行
`main()` の「移転碑の数」の行の直後に、次の2行を足す：
```
地形分類を地域版で補った碑: <数>
地形分類のデータなし（地域版でも補えない）: <数>
```
- 補った碑＝表の「（地域版）」または「（広域版）」になる碑の数。データなし＝ポップアップが「データなし」になる碑の数。
- 地域版のファイルが無いときは、補った碑 0 とし、データなしは詳細版がない碑の数。

### 5. build_site.py：県別ページ
1. データのコピー（`for csv_file in [...]` の並び）に `"landform_region"` を `"landform"` の直後に足す（`output/landform_region_{pref}.csv` → `docs/data/landform_region_{pref}.csv`。今と同じく、ファイルがあるときだけコピー）。
2. 「データのダウンロード」の「地形分類の集計」の行の直後に、次の1行を足す。**コピーしたときだけ**出す：
   `<li><a href="data/landform_region_{pref}.csv">地形分類（地域版）の集計</a></li>`
3. 「ご利用上の注意」（notice_html）の最後に、手順3と同じ文の li を1つ足す。
4. 最後の公開前チェックの対象（paths_to_check）に、コピーしたときだけ `docs/data/landform_region_{pref}.csv` を足す。
5. `required_files` には足さない（地域版の集計が無くてもページは作れるようにする）。

### 6. テスト（追加のみ）
tests/test_make_map.py に3つ：
- `test_popup_region_fill`：詳細版 `地形分類_状態`＝データなし、`地域版_状態`＝取得済（地域版）、`地域版_地形分類名`＝山地 → `地形分類：山地（地域版）</li>` を含む。
- `test_popup_region_detail_first`：詳細版 取得済・コード 1010101・分類名 氾濫平野・海岸平野、地域版 取得済（地域版）・山地 → `地形分類：氾濫平野・海岸平野</li>` を含み、`（地域版）` を含まない。
- `test_popup_region_none_and_wide`：(a) 詳細版 データなし・地域版 データなし → `地形分類：データなし</li>`。(b) 詳細版 データなし・地域版 取得済（広域版）・山地・丘陵 → `地形分類：山地・丘陵（広域版）</li>`。
tests/test_build_site.py に1つ：
- `test_build_site_region_link`：既存のテストの作り方に合わせ、`output/landform_region_{pref}.csv` を置いて build_site を実行 → docs/data にコピーされ、ページに `data/landform_region_{pref}.csv` へのリンクと「地形分類（地域版）の集計」がある。置かないときはリンクが無い（同じ関数の中で両方確かめてよい）。
