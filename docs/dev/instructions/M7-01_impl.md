## 目的（このテーマ1つ）
伝承碑の「災害名」から災害の発生年を取り出し、「建立年」との差（災害から何年後に碑を建てたか）を災害種別ごとに集計する。
あわせて、同じ災害を伝える碑のまとまり（碑群。例：昭和南海地震、安政南海地震）ごとに、碑の標高・海岸までの距離を比べる表とグラフを作る。
この指示書では分析コマンドと出力ファイルまでを作る。地図・公開ページ・更新コマンドへの組み込みは次の指示書（M7-02）で行う。

## 2. 読み取りのルール（関数に分け、それぞれ自動テストを付ける）

### 2-1 災害名から災害と発生年を取り出す　parse_disasters(text) → [(災害の名前, 年), …]
1. 文字列を Unicode の NFKC で正規化する（全角の括弧・数字・空白を半角にそろえる）
2. 「( の直後に3〜4桁の数字、続いて 年」（正規表現 `\((\d{3,4})年`）を、災害1件の始まりとする
   - 元号の年（「昭和29年」「慶応2年」など、括弧の外の年）は拾わない
3. その「(」に対応する閉じ括弧を、括弧の入れ子を数えて探す（例「(1361年7月26日(ユリウス暦))」は外側の「)」まで）
4. 災害の名前＝前の災害の閉じ括弧の次（1件目は先頭）から、この「(」の直前までの文字。前後の空白と「、」「,」「・」を除き、「ほか」を取り除く。空になったら「（名称なし）」
5. 年が1つもなければ空のリスト

既知の答え（テストに使う）：
| 入力 | 答え |
|---|---|
| 安政南海地震(1854年12月24日) | [("安政南海地震", 1854)] |
| 昭和南海地震（１９４６年１２月２１日） | [("昭和南海地震", 1946)] |
| 正平南海地震(1361年7月26日(ユリウス暦)) | [("正平南海地震", 1361)] |
| 昭和29年台風12号(ジューン台風)(1954年9月13日～14日) | [("昭和29年台風12号(ジューン台風)", 1954)] |
| 安政南海地震(1854年12月24日)大正元年の台風(1912年9月22日～23日) | [("安政南海地震", 1854), ("大正元年の台風", 1912)] |
| 安政東海地震(1854年12月23日)　安政南海地震(1854年12月24日) | [("安政東海地震", 1854), ("安政南海地震", 1854)] |
| 昭和南海地震(1946年12月21日)ほか | [("昭和南海地震", 1946)] |
| 慶応2年の寅年の大水(1866年)慶応3年の洪水(1867年) | [("慶応2年の寅年の大水", 1866), ("慶応3年の洪水", 1867)] |
| 貞観地震(869年7月13日) | [("貞観地震", 869)] |
| 地震 | [] |
| （空文字） | [] |

### 2-2 建立年を数値にする　parse_built_year(text) → 年（整数）または None
- NFKC で正規化し、3〜4桁の数字をすべて取り出して、最も小さい（古い）ものを返す。なければ None
- 既知の答え：「1861」→1861／「１８６１」→1861／「不明」→None／空文字→None／「1664(慶長碑)、不明(宝永碑)」→1664／「1900年頃」→1900

### 2-3 碑ごとの区分　（行ごとに次の順で決める）
| 条件 | 区分 | 建立までの年数 |
|---|---|---|
| 災害名から年が取れない | 不明（災害名に年なし） | 空欄 |
| 建立年が None | 対象外（建立年不明） | 空欄 |
| 建立年 ＜ 発生年（最も古い年） | 災害前の建立 | 建立年 − 発生年（マイナスのまま記録） |
| それ以外 | 差あり | 建立年 − 発生年 |
- 発生年は、取り出した年のうち最も古い年
- 集計（年数の中央値など）に使うのは「差あり」だけ。「災害前の建立」は件数だけ数える

## 3. 出力
すべて UTF-8（BOM 付き、utf-8-sig）、碑の ID などで並べ順を固定し、同じ入力なら何度実行しても同じ内容になること。小数は 小数第1位まで（標高・年数の四分位など）。距離は整数に丸めない元の値の中央値をそのまま小数第1位で。

### 3-1 output/denshou_36.csv（碑ごと、ID 順）
列：ID、碑名、主な種別、災害名（元の表記）、取り出した災害（「安政南海地震(1854)；昭和南海地震(1946)」のように全角「；」区切り）、年の数（取り出した年の個数。同じ年が2回でも2）、発生年、建立年（元の表記）、建立年_数値、建立までの年数、区分、注記
- 注記：建立年の元の表記が数字だけでない（「1664(慶長碑)、不明(宝永碑)」など）のに数値が取れたとき「建立年の記載に注記あり（最も古い年を使用）」。年の数が2以上のとき「複数の災害（最も古い年を使用）」。両方なら「／」でつなぐ。どちらもなければ空欄

### 3-2 output/denshou_summary_36.csv（主な種別ごと）
列：主な種別、碑の数、差あり、災害前の建立、対象外（建立年不明）、不明（災害名に年なし）、年数_中央値、年数_第1四分位、年数_第3四分位、年数_最小、年数_最大
- 1行目は「全種別」。そのあと主な種別を優先順（津波・高潮・洪水・土砂災害・火山災害・地震・その他）に並べ、碑の数が0の種別は出さない
- 四分位は src/summarize.py の calc_stats と同じ計算（pandas の quantile、linear）。「差あり」が0件の種別は年数の列を空欄

### 3-3 output/disaster_groups_36.csv（同じ災害の碑群）
- 碑群のキー＝（災害の名前, 発生年）。災害を2つ以上伝える碑は、それぞれの碑群に数える（例：36388-001 は安政東海地震と安政南海地震の両方）
- 列：災害の名前、発生年、碑の数、標高_中央値、標高_最小、標高_最大、標高_除外数、海岸までの距離_中央値、海岸までの距離_最小、海岸までの距離_最大、海岸までの距離_除外数、碑のID（全角「；」区切り、ID 順）
- 並び：碑の数の多い順、同数なら発生年の古い順、さらに同じなら災害の名前の順
- 名前の表記ゆれ（例「慶応2年寅の大水」と「慶応2年の寅年の大水」）はまとめない（元の表記のまま別の碑群にする）

### 3-4 グラフ（src/summarize.py のグラフと同じ大きさ・フォントの考え方で）
- output/fig/denshou_years_36.png：横軸＝主な種別（「差あり」が1件以上の種別、優先順）、縦軸＝建立までの年数（年）。碑1基を1点で描き（重なりを避けるため横に少しずらす。ずらし方は乱数を固定するか規則的にする）、種別ごとに中央値を横線で示す。横軸のラベルに件数（例「津波（44）」）を付ける。題名「災害から碑の建立までの年数（徳島県）」
- output/fig/disaster_groups_36.png：碑の数が5基以上の碑群について、左に標高、右に海岸までの距離の箱ひげ図（碑1基ずつの点も重ねる）。横軸ラベル「災害の名前（発生年）・件数」。題名「同じ災害を伝える碑群の比較（徳島県）」。5基以上の碑群がなければ図を作らず、その旨を画面に出す
- 県名は src/prefectures.py の PREFECTURES から（コードに「徳島」と直接書かない）
