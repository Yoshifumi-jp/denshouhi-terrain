## 目的（このテーマ1つ）
最寄りの河川が名前のない小水路（「名称不明」）のときに備え、「**最寄りの名前のある河川**」の名前・河川コード・距離を出力に追加する。

## 背景（変更要求 CR-5。計画書 版5・2026-10-01 本人承認）
国土数値情報の河川データ（徳島県）は 4,311本中 1,292本が名前なし（W05_004 が「名称不明」）。最寄りが名称不明の碑が9基あり、牟岐の町なかの5基は、約170m先の牟岐川ではなく5〜120m先の小水路と比べている。

## 対象ファイル
- src/add_river_coast.py
- tests/test_add_river_coast.py

## やること（手順）
1. 河川データのうち W05_004 が「名称不明」でないものだけを集めた GeoDataFrame を、process_river_coast の中で1回だけ作る（碑ごとに作り直さない）。
2. 各碑について、既存の calc_distance_and_nearest をその GeoDataFrame に使い、最寄りの名前のある河川を求める。
3. 出力列を3つ追加する。位置は「河川最近点_経度」の直後。
   - 名前のある最寄り河川名、名前のある最寄り河川コード（10桁の文字列）、名前のある河川までの距離_m（整数、今の距離と同じ丸め方）
   - 最寄り河川がもともと名前のある河川なら、同じ値が入る
   - 名前のある河川が1本もない場合は3列とも空欄
4. 高さの差・河川側の標高・河川_状態は、今までどおり「最寄り河川」（名称不明を含む）で計算する。変えない。
5. まとめ表示に1行追加：「最寄りが名称不明で、名前のある河川を別に記録した件数: n」
6. 自動テスト（ネットに接続しない）
   a. 碑から 50m に「名称不明」の川、300m に「テスト川」がある → 最寄り河川名は「名称不明」、名前のある最寄り河川名は「テスト川」、距離は 300 前後（±2m）
   b. 最寄りが名前のある川のとき → 2組の値（名前・コード・距離）が同じ
   c. 河川が「名称不明」だけのとき → 追加3列が空欄で、エラーにならない
7. 報告書を書く前に pytest 全件合格を確かめ、本体を実行して river_coast_36.csv を作り直す（問い合わせ0回の見込み）。
