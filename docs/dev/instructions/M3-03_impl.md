## 目的（このテーマ1つ）
「河川との高さの差」の河川側の標高を、粗い標高データや海・水面上の地点に頼らず、川岸の精しい標高で求めるように変える。あわせて、川から遠すぎる碑は高さの差を出さない。

## 背景（変更要求 CR-1。計画書 版3・2026-09-30 本人承認）
river_coast_36.csv（M3-01 の出力）で次が見つかった。
- 高さの差がマイナス（碑が川より低い）の碑が24基。うち22基は、河川最近点の標高が「10m」メッシュ（等高線から作った粗いデータ）だった。川の中心線上は水面のため、精しいレーザ測量のデータがなく、地理院の標高APIが粗いデータを返している（例：36383-001 牟岐大震潮記念碑は川 8.0m・碑 2.5m）
- 河川最近点が海・水面上で標高が取れない碑が5基
- 出羽島（島）の2基は、海を越えて約3.3km離れた本土の川と比べている
これは M3-01 の指示（河川最近点1点の標高を使う）の不足であり、Antigravity の実装の誤りではない。

## やること（手順）
1. **定数**を add_river_coast.py の先頭付近に置く（コメントで意味を書く）。
   - `MAX_RIVER_DIST_M = 1000`（これより遠い川とは高さの差を出さない）
   - `BANK_OFFSETS_M = [5, 10, 20, 30, 50, 100]`（河川最近点から碑の方へずらして標高を調べる距離）
   - process_river_coast の引数でも差し替えられるようにする（既定値は上の定数）
2. **川から遠い碑**：河川までの距離が MAX_RIVER_DIST_M を**超える**（1000m ちょうどは対象）ときは、河川側の標高を問い合わせず、高さの差を空欄、河川_状態を「高さの差 対象外（河川まで1000m超）」とする。最寄り河川名・河川コード・距離・河川最近点の緯度経度は今までどおり記録する。
3. **調べる地点（候補）を作る関数**を、ファイルを読まない関数として作る。
   - 名前：`make_bank_points(river_xy, monument_xy, dist_m, offsets)`
   - 平面直角座標（m）で、河川最近点 P から碑 M の方向へ、offsets の各距離だけ進んだ点の一覧を返す。**距離が dist_m 以上のものは含めない**（碑を越えない）
   - 返す一覧の先頭は P 自身（ずらし距離 0）とする
   - 各点は緯度・経度（EPSG:6668、小数6桁）に戻してから標高を問い合わせる（今と同じ）
4. **標高の問い合わせ**：各候補点を、今と同じ get_elevation_with_cache で問い合わせる（キャッシュ共用・1秒以上空ける・add_elevation.py は変えない）。
5. **河川側の標高を選ぶ関数**を、ファイルを読まない関数として作る。
   - 名前：`choose_bank_elevation(results)`。results は候補ごとの（ずらし距離, 標高, 標高データ種別, 状態, 緯度, 経度）の一覧
   - 「精しい値」＝標高が数値で、データ種別が「10m」で始まらないもの（「1m（レーザ）」「5m（レーザ）」「5m（写真測量）」など。種別が空のときも精しい値として扱う）
   - 決め方（上から順に当てはめる）
     1. 状態が「通信エラー」の候補が1つでもある → 河川_状態「高さの差 取得不可（通信エラー）」（再実行で取り直せるように）
     2. 精しい値が1つ以上ある → その中で**最も低い値**を採用し、河川_状態「取得済」（低い方を選ぶのは、堤防の上の値を避けるため）
     3. 精しい値がなく、P 自身の値が数値（10m メッシュ）→ その値を採用し、河川_状態「取得済（参考値：10mメッシュ）」
     4. どれにも当たらない → 河川_状態「高さの差 取得不可（河川の標高なし）」
   - 採用した値について、標高・データ種別・その地点の緯度経度を返す
6. **高さの差**＝碑の標高 − 採用した河川側の標高（小数1桁）。碑の標高がないときは今までどおり「高さの差 取得不可（碑の標高なし）」。状態の優先順は：対象外（手順2）→ 通信エラー → 河川の標高なし → 碑の標高なし → 取得済／参考値。
7. **出力の列**を次に変える（data/processed/river_coast_<県コード>.csv、UTF-8 BOM付き、ID 昇順は今のまま）。
   ID, 碑名, 緯度, 経度, 最寄り河川名, 河川コード, 河川までの距離_m, 河川最近点_緯度, 河川最近点_経度, 河川側の標高_m, 河川側の標高_種別, 河川側の標高_緯度, 河川側の標高_経度, 碑の標高_m, 河川との高さの差_m, 河川_状態, 海岸までの距離_m, 海岸_状態, 取得日
   - 「河川最近点の標高_m」列はなくし、「河川側の標高_m」に置き換える
   - 河川_状態は次のいずれか：「取得済」「取得済（参考値：10mメッシュ）」「高さの差 対象外（河川まで1000m超）」「高さの差 取得不可（碑の標高なし）」「高さの差 取得不可（河川の標高なし）」「高さの差 取得不可（通信エラー）」
8. **画面表示**：1行ずつの表示の「高さの差」の後に、参考値のときは「（参考値）」、対象外のときは「対象外」と出す。最後のまとめに次を追加する。
   - 河川_状態ごとの件数（上の6種類すべて。0件も表示）
   - 高さの差がマイナスの件数
9. **自動テスト**を追加する（ネットに接続しない。tmp_path を使う。M3-02 で直したテストはすべて合格のまま残す）。
   a. make_bank_points：P(0,0)・M(0,100)・距離100 → P と (0,5)(0,10)(0,20)(0,30)(0,50) の6点（100 は含まない）
   b. make_bank_points：P(0,0)・M(0,8)・距離8 → P と (0,5) の2点
   c. choose_bank_elevation：P＝6.0（10m）、5m先＝3.2（1m（レーザ））、10m先＝2.9（5m（レーザ））→ 2.9 を採用・「取得済」・種別「5m（レーザ）」
   d. choose_bank_elevation：P＝6.0（10m）、他はすべて "-----" → 6.0 を採用・「取得済（参考値：10mメッシュ）」
   e. choose_bank_elevation：すべて "-----" → 空欄・「高さの差 取得不可（河川の標高なし）」
   f. choose_bank_elevation：精しい値があっても、1つが「通信エラー」→「高さの差 取得不可（通信エラー）」
   g. 河川までの距離が 1200m の碑：河川_状態「高さの差 対象外（河川まで1000m超）」、高さの差が空欄、問い合わせ関数が呼ばれない（呼ばれた回数0回）
   - M3-02 の test_height_diff の5つの場合は、この変更後も期待値どおりであること。テスト用の河川までの距離が1000mを超えていて「対象外」になってしまう場合に限り、テストの座標を近づけてよい（期待値は変えない）。その場合は報告に書く
10. 報告書を書く前に `.venv\Scripts\python -m pytest` を実行し、全件合格を確かめる。
