# 指示書 M6-04（修正・トップページの比較表）　作成日：2026-10-03

最初に AGENTS.md を読んでから作業してください（特に「個人情報の扱い」）。
作業前に、エディタのタブをすべて閉じてから始めてください（ファイル消失の再発防止）。

## 目的（このテーマ1つ）
docs/index.html の「碑とまわりの比較」の表で、「碑の中央値」「差の中央値」が空欄になる不具合を直し、本物の列名で確かめるテストにする。

## 対象ファイル
- src/build_site.py、tests/test_build_site.py
- 生成物：docs/index.html ほか（build_site.py の再実行で作り直す）

## 不具合の内容
- 起きていること：公開ページの比較表で「碑の中央値」「差の中央値」が5行とも空欄
- 本来の動き：標高の行なら「標高(m)｜4.0｜38.5｜-28.0｜14%」と出る
- 原因の見立て（Claude のソース確認 M6_review-3 No.1）：build_site.py が `row.get('中央値')`、`row.get('差_中央値')` で値を取っているが、output/summary_36.csv の列名は「碑_中央値」「差の中央値」。テストの偽 summary も同じ誤った列名で作っているため、テストが通ってしまう

## やること（手順）
1. build_site.py の比較表で、列名を本物どおり「碑_中央値」「比較地点_中央値」「差の中央値」「碑の方が大きい割合」にする。
2. 必要な列が summary にないときは、黙って空欄にせず、足りない列名を表示して終了コード1にする。
3. M6_review-3 No.7 の整理：何もしない `if … : pass` とコメントを消す／`except:` を `except (TypeError, ValueError):` にする／monuments のフォルダを引数（例 data_dir、既定 PROJECT_ROOT / "data" / "processed"）で渡せるようにし、output_dir の親から推測する書き方をやめる／出典の「背景地図：地理院タイル（淡色地図）」の「地理院タイル」の語に地理院タイル一覧（https://maps.gsi.go.jp/development/ichiran.html）へのリンクを付け、別の行の「地理院タイル一覧」は消す（文言はほかは変えない）。
4. tests/test_build_site.py を直す：
   - 偽の summary は **本物の output/summary_36.csv と同じ列名・同じ列の並び**で作る（16列：範囲,災害種別,指標,碑_数,碑_除外数,碑_中央値,碑_第1四分位,碑_第3四分位,比較地点_数,比較地点_除外数,比較地点_中央値,比較地点_第1四分位,比較地点_第3四分位,組の数,差の中央値,碑の方が大きい割合）
   - c：標高の行が `<tr><td>標高(m)</td><td>10</td><td>5</td><td>5</td><td>14%</td></tr>` のように、**行全体**で一致することを確かめる（「移転碑を除く」の行は、その行にしかない値（例 999）が index.html にないことで確かめる。'11' のような短い数字は使わない）
   - c2（新規）：必要な列が1つない summary で、終了コード1と列名の表示
   - d：「完了」の2行が新しい順（2026-09-24 の行が 2026-09-20 の行より前）に出ることを、文字の位置で確かめる
   - c3（新規・読むだけ）：本物の output/summary_36.csv があるときだけ（なければ skip）、その列名に build_site が使う列名がすべて含まれること
5. `.\.venv\Scripts\python.exe src\build_site.py --pref 36` を実行し直す。
