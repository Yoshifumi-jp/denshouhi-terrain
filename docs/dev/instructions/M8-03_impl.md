## 3. 集計のルール（関数に分け、それぞれ自動テストを付ける）
- 範囲：「全碑」「移転碑を除く」
- 災害種別（碑の種別。比較地点は points の種別列＝元の碑の種別）：全種別、洪水、地震、津波、土砂災害、高潮、火山災害、その他（この順）。1基が複数の種別を持つときは、それぞれに数える
  - **碑が0基の災害種別は行を出さない**（徳島では火山災害）
- ハザード（この順、表の文字をそのまま使う）

| ハザード（出力の文字） | 列の頭 | 浸水深3m以上を数えるか |
|---|---|---|
| 洪水（想定最大規模） | 洪水_ | 数える |
| 津波 | 津波_ | 数える |
| 高潮 | 高潮_ | 数える |
| 土砂災害 | 土砂_ | 数えない（列は空欄） |

- 数（分母）：状態が「区域内」または「区域外」の件数。「取得不可」は分母から除き、取得不可の列に件数を出す
- 区域内：状態が「区域内」の件数。区域内の割合＝区域内÷数
- 3m以上：浸水深が「3m〜5m」「5m〜10m」「10m〜20m」「20m以上」の件数（src/hazard_layers.py の凡例の文字と一致させる。「0.5m〜3m」は含めない）。3m以上の割合＝3m以上÷数（分母は区域内の件数ではなく「数」）
- 割合は Python の `round(値, 3)`。数が0のとき割合は空欄
