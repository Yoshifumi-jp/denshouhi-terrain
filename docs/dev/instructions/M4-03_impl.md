## 目的（このテーマ1つ）
M4-01 で作った比較地点と碑の地形情報を突き合わせ、「碑はまわりより高い／低い、川や海に近い／遠い場所にあるか」を災害種別ごとに集計し、表とグラフを output/ に出す。
あわせて、伝承内容に「移転」「移設」がある碑に印を付け、集計を「全碑」と「移転碑を除く」の両方で出す（CR-3 A）。
ネットへの問い合わせは行わない（data/processed/ の CSV だけを読む）。

## 対象ファイル
- 新規：src/summarize.py、tests/test_summarize.py
- 変更：requirements.txt（matplotlib を追加。例 `matplotlib>=3.8`）、.venv に matplotlib をインストール
- 既存の src/ の各ファイルは変更しない

## 入力（すべて data/processed/、県コード 36 の例）
- 碑：monuments_36.csv、elevation_36.csv、river_coast_36.csv、landform_36.csv
- 比較地点：points_36.csv、elevation_points_36.csv、river_coast_points_36.csv、landform_points_36.csv
- ID で結合する。比較地点の災害種別・種別_7列は points_36.csv の値を使う（元の碑と同じ）
- どれかのファイルが無いときは、足りないファイル名と、先に実行するコマンドを出して終わる

## 指標と、集計に使う値の条件（条件に合わない値は、その指標だけ「除外」として数える）
| 指標 | 列 | 使う条件 |
|---|---|---|
| 標高_m | elevation の 標高_m | 取得状態＝取得済 |
| 傾斜_度 | elevation の 傾斜_度 | 取得状態＝取得済 |
| 河川までの距離_m | river_coast の 河川までの距離_m | 値がある |
| 河川との高さの差_m | river_coast の 河川との高さの差_m | 河川_状態＝「取得済」のみ（参考値・対象外・取得不可は除外） |
| 海岸までの距離_m | river_coast の 海岸までの距離_m | 海岸_状態＝取得済 |
| 地形分類名 | landform の 地形分類名 | 地形分類_状態＝取得済 かつ 地形分類コードが空でない（M4_review-1 No.5：code が空の1件は除外に数える） |

## 移転碑の印
- monuments の 伝承内容 に「移転」または「移設」を含む碑を「移転碑」とする
- output/relocated_36.csv に一覧を出す（列：ID、碑名、所在地、該当語、伝承内容の該当箇所の前後30字）
- 比較地点は、元の碑が移転碑ならその比較地点も「移転碑を除く」集計から外す

## 集計の単位
- 災害種別：「全種別」＋ 種別_7列それぞれ（1基が複数の種別を持つため、種別ごとの合計は碑の数より多くなる。表の下に注記を1行出す）
- 範囲：「全碑」と「移転碑を除く」の2通り
- 碑数が0の種別（徳島では火山災害）も行は出し、値は空欄にする

## 出力（output/ フォルダ。無ければ作る。utf-8-sig）
1. **output/summary_36.csv**（数値の指標の比較）。1行＝範囲×災害種別×指標。列：
   範囲、災害種別、指標、碑_数、碑_除外数、碑_中央値、碑_第1四分位、碑_第3四分位、比較地点_数、比較地点_除外数、比較地点_中央値、比較地点_第1四分位、比較地点_第3四分位、組の数、差の中央値、碑の方が大きい割合
   - 「組」：碑ごとに「碑の値 − その碑の比較地点（使える値のもの）の中央値」を計算する。碑の値が除外、または使える比較地点が0点の碑は組に入れない
   - 差の中央値：組の差の中央値。碑の方が大きい割合：差が正の組の数 ÷ 組の数（小数3桁）
   - 数値は小数2桁に丸める。四分位は pandas の quantile（既定の線形補間）でよい
2. **output/landform_36.csv**（地形分類の構成比）。1行＝範囲×災害種別×地形分類名。列：範囲、災害種別、地形分類名、碑_件数、碑_割合、比較地点_件数、比較地点_割合（割合は除外を除いた件数に対する比、小数3桁）。地形分類名の並びは、全種別・全碑の比較地点の件数が多い順
3. **output/relocated_36.csv**（上記）
4. **グラフ（output/fig/、PNG）**：範囲「全碑」のみ。碑数5基以上の災害種別と「全種別」を対象にする
   - 数値の指標ごとに1枚（box_標高_m_36.png など。ファイル名は英数字で box_elevation_36.png、box_slope_36.png、box_river_dist_36.png、box_river_height_36.png、box_coast_dist_36.png）：横軸に災害種別、各種別に「碑」と「比較地点」の箱ひげ図を並べる。凡例・軸ラベル・タイトルは日本語
   - 地形分類の構成比を1枚（bar_landform_36.png）：「全種別」の碑と比較地点の積み上げ横棒
   - 日本語フォントは Windows の「Yu Gothic」「Meiryo」「MS Gothic」の順で、見つかったものを使う（文字化け・豆腐にしない）
   - 各図の下に出典「出典：国土地理院（自然災害伝承碑、標高、地形分類）、国土数値情報（河川、海岸線）を加工して作成」を入れる
5. まとめ表示：対象の県名／碑の数（全碑・移転碑を除く）／比較地点の数（全碑・移転碑を除く）／移転碑の ID と碑名／指標ごとの除外数（碑・比較地点）／出力したファイル名の一覧

## テスト（tests/test_summarize.py。tmp_path に小さな偽データの CSV を作って動かす。本物の data/ は読まない）
- a. 碑3基（A・B・C）、比較地点 各2〜3点の偽データで、summary の 碑_中央値・比較地点_中央値・差の中央値・碑の方が大きい割合 が手計算の値と一致する（手計算の値をテストに直接書く）
- b. 伝承内容に「移転」がある碑は「移転碑を除く」から外れ、その比較地点も外れる。「移設」でも同じ
- c. 河川_状態が「取得済（参考値：10mメッシュ）」の碑は、河川との高さの差だけ除外に数えられ、他の指標には入る
- d. 地形分類コードが空の行は地形分類の除外に数えられ、構成比の分母に入らない
- e. 種別を2つ持つ碑が、両方の種別の行に数えられる。全種別の碑_数（除外0のとき）は碑の数と同じ
- f. 使える比較地点が0点の碑は「組」に入らない
- g. 同じ入力で2回実行すると、出力 CSV 3つが完全に一致する
- h. 入力ファイルが1つ欠けているとき、ファイル名を出して終わる（SystemExit）
