## やること（手順）
VS Code のターミナル（PowerShell）で、プロジェクトのフォルダから順に実行する。Python は必ず `.\.venv\Scripts\python.exe` で呼ぶ。

1. 地図を47都道府県分作り直す（1県ずつ。途中で失敗したら止まる）：
   ```powershell
   foreach ($i in 1..47) { $c = "{0:D2}" -f $i; Write-Output "=== $c ==="; .\.venv\Scripts\python.exe src\make_map.py --pref $c; if ($LASTEXITCODE -ne 0) { Write-Output "失敗：$c"; break } }
   ```
2. 県別ページを47都道府県分作り直す：
   ```powershell
   .\.venv\Scripts\python.exe src\build_site.py --pref all
   ```
3. 公開前チェック：
   ```powershell
   .\.venv\Scripts\python.exe src\check_public.py
   ```
4. `git status --short` を実行し、変わったファイルの種類と個数を確かめる（下の「既知の答え」）。
