## やること
1. src/summarize_artificial.py を作る。作りは src/summarize_region.py にならい、次を import して使う（自分で同じ処理を書き直さない）：
   `PREFECTURES`（prefectures）、`extract_relocated`・`DISASTER_TYPES`（summarize）、`write_with_notes`（summarize_region。表を LF で書いてから注の行を書く関数）、`parse_pref_arg`（load_monuments）。
   import は既存と同じく `try: from src.xxx import ... / except ImportError: from xxx import ...` の形。
   - `main(args=None, base_dir=None)`。引数：`--pref`（省略可。01〜47 のカンマ区切り、または all。省略時は all）。不正なときは parse_pref_arg のエラー文を出して終了コード 1
   - 入力（県ごと、data/processed/）：monuments_XX.csv、points_XX.csv、landform_artificial_XX.csv、landform_artificial_points_XX.csv、landform_XX.csv、landform_points_XX.csv（**6ファイル**。最後の2つは「自然地形×人工地形」の自然地形〔詳細版の `地形分類名`〕に使う）。
     ID 系の列（ID・元の碑ID）と人工地形・地形分類の列は文字列で読む。monuments／points に `人工地形名`・`人工地形_状態`（人工地形の CSV から）と `地形分類名`（詳細版の CSV から）を ID で左結合する。結合できなかった値は空文字
   - 入力の確認：対象の県で6ファイルのどれかがない県があれば、`エラー：ファイルが足りない県があります：県名（XX）、県名（YY）` と
     `先に実行してください：python src/run_artificial_batch.py --pref "XX,YY"` を出して終了コード 1（何も書き出さない）
2. 集計の決まり
   - 「人工地形の区分」を1地点ごとに決める：`人工地形_状態` が「取得済」→ `人工地形名`、「人工地形なし」→「人工地形なし」、「範囲外」「取得不可」→ 数えない
   - 数える地点（分母）は「取得済」と「人工地形なし」の地点。割合は、そのグループで数えた地点に対する割合で、小数3桁に丸める。分母が 0 なら 0
   - 区分の行の順番は固定：`盛土地・埋立地, 切土地, 干拓地, 農耕平坦化地, 改変工事中, 人工地形なし`（どのグループにも6行すべて出す。0件の行も出す）。
     この5つ以外の人工地形名（「不明（code=…）」など）が出てきたときは、改変工事中の後・人工地形なしの前に名前順で足す（今の全国データには出ない）
   - 範囲は「全碑」「移転碑を除く」の2つ。移転碑は extract_relocated で決め、比較地点は `元の碑ID` で除く（summarize_region.py と同じ）。県別ファイルではその県の碑だけで、全国ファイルでは47県をつないだ碑で extract_relocated を使う
   - **表1「災害種別×人工地形」**（県別 output/landform_artificial_XX.csv と全国 output/landform_artificial_all.csv、同じ関数で作る）
     - 災害種別は「全種別」＋ DISASTER_TYPES の7つ（表示名は先頭の「種別_」を取る）。碑・比較地点とも、それぞれの `種別_xxx` 列が 1 の行
     - 列：`範囲,災害種別,人工地形名,碑_件数,碑_割合,比較地点_件数,比較地点_割合`
     - 行の並び：範囲（全碑→移転碑を除く）→ 災害種別（全種別→洪水→地震→津波→土砂災害→高潮→火山災害→その他）→ 区分（上の固定順）。行数は 2×8×6＝96
   - **表2「自然地形×人工地形」**（全国だけ output/landform_artificial_cross_all.csv。災害種別は分けない）
     - 自然地形は詳細版の `地形分類名`。数える地点は表1と同じ（人工地形の「取得済」「人工地形なし」）
     - 列：`範囲,自然地形名,人工地形名,碑_件数,碑_割合,比較地点_件数,比較地点_割合`。割合は **同じ範囲・同じ自然地形の中で** 数えた地点に対する割合
     - 行の並び：範囲（全碑→移転碑を除く）→ 自然地形 → 区分（上の固定順）。自然地形は、そのファイルに1回でも出てくるものをすべて、どちらの範囲にも同じ順で出す。
       順番は「全碑の比較地点の件数の多い順 → 同数なら全碑の碑の件数の多い順 → 同数なら名前順」
   - 注の行（表の後ろに書く。この文言・この順。a〜d はそのファイルの「全碑」の範囲での件数。3桁区切りなし）
     - 表1：
       ```
       注：1基が複数の災害種別を持つため、種別ごとの合計は全種別の碑の数より多くなる場合があります。
       注：人工地形は、地形分類（自然地形）の詳細版で値が取れた地点だけで調べています。割合は「人工地形あり」と「人工地形なし」を合わせた数に対する割合です。
       注：数えていない地点：範囲外（詳細版のデータなし）碑 a・比較地点 b、取得不可 碑 c・比較地点 d
       出典：国土地理院 地形分類（人工地形）を加工して作成
       ```
     - 表2：
       ```
       注：自然地形は地形分類（自然地形）の詳細版の分類名です。割合は、同じ自然地形の中で数えた地点に対する割合です。
       注：数えていない地点：範囲外（詳細版のデータなし）碑 a・比較地点 b、取得不可 碑 c・比較地点 d
       出典：国土地理院 地形分類（自然地形）・地形分類（人工地形）を加工して作成
       ```
3. 出力（output/、UTF-8 BOM 付き、**改行 LF**）
   - `--pref` で指定した各県：output/landform_artificial_XX.csv

   - 県を指定したとき（例 `--pref 36`）：1行目を `地形分類（人工地形）の集計：徳島県（36）`（複数県なら `地形分類（人工地形）の集計：2都道府県`）にし、2〜5行目は対象の県を合わせた数。
