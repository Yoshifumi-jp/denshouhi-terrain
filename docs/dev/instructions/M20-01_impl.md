## 目的（このテーマ1つ）
県別の表示（地図のポップアップと県別ページ）に、地形分類（人工地形）を反映する。
表示の決まり（計画書 版13）：**人工地形があるときだけ、ポップアップの「地形分類：」の行の直後に1行足す**。自然地形と混ぜない（「地形分類：」の行は今のまま変えない）。

## 対象ファイル
- src/make_map.py（変更）
- src/build_site.py（変更）
- tests/test_make_map.py（テスト関数を3つ追加。既存のテストは変えない）
- tests/test_build_site.py（テスト関数を1つ追加。既存のテストは変えない）

## やること（手順）

### 1. make_map.py：人工地形の読み込み
1. `load_data(pref)` で、地域版の結合の直後に、碑の表へ `data/processed/landform_artificial_{pref}.csv` を ID で左結合する。使う列は `ID`・`人工地形名`・`人工地形_状態` の3列だけ（碑名・緯度・経度・コード・重なり数・取得日は結合しない）。
2. このファイルが無いときは止めずに、次の1行を表示して続ける（人工地形の列は無いものとして扱う）：
   `人工地形のファイルがありません（landform_artificial_{pref}.csv）。人工地形は表示しません`
   ※ {pref} は県コード（例 36）に置き換える。

### 2. make_map.py：ポップアップに「人工地形：」の行
`build_popup_html` で、`<li>地形分類：{lf_text}</li>` の**直後**に、次の条件のときだけ1行足す：
- 条件：`人工地形_状態` が `取得済` で、`人工地形名` が空でない（NaN・空文字でない）
- 足す行：`<li>人工地形：<人工地形名></li>`（例：`<li>人工地形：干拓地</li>`）。名前は今の esc で html エスケープする。
- 条件に合わないとき（人工地形なし・範囲外・取得不可・列が無い・空）は何も足さない（今とまったく同じ html）。
- 関数の引数は増やさない（row の列から判定する）。既存のテストがそのまま通ること。

### 3. make_map.py：凡例の「出典・ご利用上の注意」に2行
1. 「地形分類：国土地理院 地形分類（自然地形）」の li の直後に、次の li を足す：
   `地形分類（人工地形）：国土地理院 地形分類（人工地形）`
2. 「地形分類で「（地域版）」と付いたものは、…」の li の直後に、次の li を足す：
   `人工地形（盛土地・埋立地、干拓地、切土地など）は、地形分類の詳細版がある範囲だけで調べています。データを整備した時点の状態で、その後の造成・埋立は入っていません。`
- ※ どちらの文にも「人工地形：」（全角コロンが「人工地形」の直後に来る形）は含めない。地図ファイルの「人工地形：」の数＝ポップアップの行の数、として数えるため。

### 4. make_map.py：実行時のまとめ表示に1行
`main()` の「地形分類のデータなし（地域版でも補えない）: 」の行の直後に、次の1行を足す：
```
人工地形のある碑: <数>
```
- 数＝手順2の条件に合う碑の数（＝ポップアップに「人工地形：」の行が出る碑の数）。人工地形のファイルが無いときは 0。

### 5. build_site.py：県別ページ
1. データのコピー（`for csv_file in [...]` の並び）に `"landform_artificial"` を `"landform_region"` の直後に足す（`output/landform_artificial_{pref}.csv`〔M19-02 の県別集計〕→ `docs/data/landform_artificial_{pref}.csv`。今と同じく、ファイルがあるときだけコピー）。コピーしたかどうかを `landform_artificial_copied` で覚える（地域版と同じ書き方）。
2. 「データのダウンロード」の地域版の行（`landform_region_li`）の直後に、次の1行を足す。**コピーしたときだけ**出す：
   `<li><a href="data/landform_artificial_{pref}.csv">地形分類（人工地形）の集計</a></li>`
3. 出典の ul（「地形分類：国土地理院 地形分類（自然地形）」の li があるもの）で、その li の直後に手順3-1と同じ文の li を足す。
4. 「ご利用上の注意」（notice_html）の最後に、手順3-2と同じ文の li を1つ足す。
5. 最後の公開前チェックの対象（paths_to_check）に、コピーしたときだけ `docs/data/landform_artificial_{pref}.csv` を足す。
6. `required_files` には足さない（人工地形の集計が無くてもページは作れるようにする）。

### 6. テスト（追加のみ）
tests/test_make_map.py に3つ：
- `test_popup_artificial_line`：詳細版 取得済・コード 1010101・分類名 旧水部、`人工地形_状態`＝取得済、`人工地形名`＝干拓地 → `地形分類：旧水部</li>` の直後に `<li>人工地形：干拓地</li>` が続く（間に空白・改行があってもよい。「地形分類：旧水部</li>」の位置より後ろ、かつ「最寄り河川：」より前にあることを確かめる）。
- `test_popup_artificial_absent`：(a) `人工地形_状態`＝人工地形なし・名前は空 (b) `人工地形_状態`＝範囲外・名前は空 (c) 人工地形の列が無い row → どれも `人工地形：` を含まない。
- `test_popup_artificial_escape`：`人工地形名`＝`<b>盛土地</b>`（状態 取得済）→ `人工地形：&lt;b&gt;盛土地&lt;/b&gt;</li>` を含み、`<b>盛土地</b>` をそのままは含まない。
tests/test_build_site.py に1つ：
- `test_build_site_artificial_link`：既存のテスト（test_build_site_region_link）の作り方に合わせ、`output/landform_artificial_{pref}.csv` を置いて build_site を実行 → docs/data にコピーされ、ページに `data/landform_artificial_{pref}.csv` へのリンクと「地形分類（人工地形）の集計」がある。置かないときはリンクが無い（同じ関数の中で両方確かめてよい）。
