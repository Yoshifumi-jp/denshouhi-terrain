## 不具合の内容
1. 名前のある最寄り河川の距離が出ない（中）
   - 起きていること：36383-002 で「名前のある最寄り河川：瀬戸川（データなし）」
   - 本来の動き：「瀬戸川（3416 m）」
   - 原因：build_popup_html が列「名前のある最寄り河川までの距離_m」を読んでいる。river_coast_36.csv の実際の列名は **「名前のある河川までの距離_m」**
2. 標高にデータ種別が出ない（中）
   - 起きていること：「標高：1.6 m」
   - 本来の動き：「標高：1.6 m（1m（レーザ））」。データ種別は elevation_36.csv の列「標高データ種別」。種別が空のときは「1.6 m」だけ。取得状態が取得済でないときは今までどおり状態の文字列
3. 災害名などに見出しがない（軽微）
   - 今の「安政南海地震(…) / 地震・津波 / 1861 / 徳島県…」を、次の4行にする（値は html.escape したまま）
     - 災害名：…
     - 災害種別：…
     - 建立年：…（「不明」はそのまま）
     - 所在地：…
4. load_data の read_csv に encoding='utf-8-sig' を付ける（軽微。既存の summarize.py と同じ書き方）
