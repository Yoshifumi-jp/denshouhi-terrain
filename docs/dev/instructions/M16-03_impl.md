## やること
1. src/count_missing.py の COLUMNS の**最後**（`通信エラー_比較地点` の後ろ）に、次の6列をこの順で足す。既存の20列の名前・順番・値の計算は変えない。
   ```
   地域版_データなし_碑, 地域版_データなし_比較地点,
   地域版_取得不可_碑, 地域版_取得不可_比較地点,
   詳細版データなしを補えた_碑, 詳細版データなしを補えた_比較地点
   ```
2. 県ごとの集計（count_missing 関数）
   - 読むファイル：既存の8ファイルに加え、data/processed/landform_region_XX.csv と landform_region_points_XX.csv（列 `ID`・`碑名`・`地域版_状態` を使う。ID は文字列で読む）
   - **地域版の2ファイルは必須にしない**。既存の8ファイルがそろっていれば、その県は今までどおり結果の行に入れる（missing_prefs にも入れない）。
     地域版の2ファイルのどちらかがない県は、追加の6列を空欄（""）にし、その県コードを新しいリスト `region_missing_prefs` に入れる
   - 各列の数え方（`地域版_状態` の値で数える）：
     - 地域版_データなし：「データなし」の行数
     - 地域版_取得不可：「取得不可」の行数
     - 詳細版データなしを補えた：landform_XX.csv（比較地点は landform_points_XX.csv）の `地形分類_状態` が「データなし」の行のうち、
       ID で結合した `地域版_状態` が「取得済（地域版）」または「取得済（広域版）」の行数
   - 全国の合計行：追加の6列は、地域版の2ファイルがそろっている県だけを足した数（そろっている県が0なら空欄）
   - 関数の戻り値に `region_missing_prefs` と、地域版で「データなし」の碑の一覧（県コード順・ファイルの行順の (ID, 碑名) のリスト。地域版の2ファイルがそろっている県だけ）を加える。
     既存のテストが `df, missing_prefs = count_missing(...)` で受けているので、**count_missing の戻り値は今の2つのまま変えず**、
     地域版の情報は別の関数（例 `count_region(base_dir, pref_codes)`）で作り、main の中で列に足す作りにしてよい。どちらの作りでも、既存のテスト関数を変えずに全件合格すること
3. CSV の書き出しを LF にする：`df.to_csv(out_file, index=False, encoding="utf-8-sig", lineterminator="\n")`（空欄は空のまま）
4. 画面の表示：既存の行は文言・順番を変えず、`地形分類のデータなし：…` の行の**直後**に次の4行を足す（数は3桁区切り、割合は小数1桁の%）。
   ```
   地域版のファイルが足りない県：なし
   地形分類（地域版）のデータなし：碑 5（0.2%）／比較地点 118（1.0%）、取得不可：碑 0／比較地点 0
   詳細版のデータなしを地域版・広域版で補えた地点：碑 927／929（99.8%）、比較地点 4,818／4,890（98.5%）
   地形分類（地域版）のデータなしの碑：36383-002 出羽島観栄寺石碑(旧碑)、36383-003 出羽島観栄寺石碑(再建)、38203-001 デラ台風日振島遭難者慰霊塔、40130-001 福岡県西方沖地震復興記念碑、43212-009 一ちょ墓 供養塔
   ```
   - 1行目：足りない県があれば `地域版のファイルが足りない県：県名（XX）、県名（YY）（地域版の列は空欄です。先に実行してください：python src/run_region_batch.py --pref "XX,YY"）`
   - 2行目の割合の分母は、地域版の2ファイルがそろっている県の碑・比較地点の数。3行目の分母は、そろっている県の詳細版「データなし」の数。分母が0なら 0.0%
   - 4行目：一覧は最大10基を「ID 碑名」で「、」区切り。11基以上なら10基の後ろに `、ほか n基`。0基なら `なし`
   - そろっている県が1つもないときは、2〜4行目を出さず1行目だけを出す
5. tests/test_count_missing.py にテスト関数を足し、`python -m pytest -q` を実行する（tmp_path に偽の data/processed を作る）。最低限：
   (a) 地域版の2ファイルがある県で、6列の数（データなし・取得不可・補えた〔地域版・広域版の両方を数え、データなし・取得不可は数えない〕）と全国の合計が正しい
   (b) 地域版のファイルがない県：結果の行に入る、missing_prefs に入らない、6列が空欄、全国の合計に入らない、画面の1行目に県名と run_region_batch.py の案内が出る
   (c) 画面の4行が「地形分類のデータなし」の行の直後にこの順で出る。データなしの碑が11基以上のとき「、ほか n基」、0基のとき「なし」
   (d) 出力の CSV が BOM 付き・LF（\r を含まない）、列が COLUMNS（26列）と同じ順
   (e) 実データでの照合（data/processed に47県の10ファイルがそろっているときだけ。なければ pytest.skip）：
       全国の 地域版_データなし 碑5・比較地点118、地域版_取得不可 0・0、詳細版データなしを補えた 碑927・比較地点4,818。
       徳島（36）は 2・6・0・0・11・62、岩手（03）は 0・17・0・0・149・737。既存の20列の全国の値は既存の test_real_data と同じ。
       （output/ には書かない。集計の関数を直接呼ぶ）
6. `python src/count_missing.py` を実行する（output/missing_counts.csv が書き換わる）。
7. 完了後、自己チェックを行い、docs/dev/reports/M16-03_report.md に報告を書く（6 の画面の表示は全文をそのまま貼る）。
