## 目的（このテーマ1つ）
計画書 版13 の M19「count_missing.py に人工地形の『範囲外』『取得不可』を追加」を行う。
あわせて、人工地形の「範囲外」が地形分類（詳細版）の「データなし」と同じ数になっているか（人工地形は詳細版で値が取れた地点だけで調べる決まり）を画面で確かめられるようにする。
update_all.py・update.py への組み込みは次の指示書（M19-04）で行うので、今回は触らない。

## やること
1. src/count_missing.py の COLUMNS の**最後**（`詳細版データなしを補えた_比較地点` の後ろ）に、次の4列をこの順で足す（合計30列）。既存の26列の名前・順番・値の計算は変えない。
   ```
   人工地形_範囲外_碑, 人工地形_範囲外_比較地点,
   人工地形_取得不可_碑, 人工地形_取得不可_比較地点
   ```
   4列の名前のリストを `ARTIFICIAL_COLS` として REGION_COLS の後ろに置く。
2. 県ごとの集計：第3版の地域版（count_region）と同じ作りで、新しい関数 `count_artificial(base_dir=None, pref_codes=None)` を作る
   - 読むファイル：data/processed/landform_artificial_XX.csv と landform_artificial_points_XX.csv（列 `ID`・`人工地形_状態` を使う。ID は文字列で読む）
   - **人工地形の2ファイルは必須にしない**。既存の8ファイルがそろっていれば、その県は今までどおり結果の行に入れる（missing_prefs にも入れない）。
     人工地形の2ファイルのどちらかがない県は、4列を空欄（""）にし、その県コードを `artificial_missing_prefs` に入れる
   - 数え方（`人工地形_状態` の値で数える）：範囲外＝「範囲外」の行数、取得不可＝「取得不可」の行数
   - 全国の合計行：4列は、人工地形の2ファイルがそろっている県だけを足した数（そろっている県が0なら空欄）
   - 戻り値は `(県コード別の4列の辞書〔"全国" を含む〕, artificial_missing_prefs)`
   - count_missing の中で、地域版と同じ場所・同じやり方で4列を行に足す。**count_missing の戻り値は今の2つ（df, missing_prefs）のまま変えない**
3. CSV の書き出しは今のまま（BOM 付き・LF）。空欄は空のまま
4. 画面の表示：既存の行は文言・順番を変えず、`地形分類（地域版）のデータなしの碑：…` の行（地域版の4行の最後。地域版の県が0で1行だけのときは `地域版のファイルが足りない県：…` の行）の**直後**に次の3行を足す（数は3桁区切り、割合は小数1桁の%）。
   ```
   人工地形のファイルが足りない県：なし
   地形分類（人工地形）の範囲外：碑 929（37.4%）／比較地点 4,890（39.5%）、取得不可：碑 0／比較地点 0
   人工地形の範囲外と地形分類（詳細版）のデータなし：一致（碑 929・比較地点 4,890）
   ```
   - 1行目：足りない県があれば `人工地形のファイルが足りない県：県名（XX）、県名（YY）（人工地形の列は空欄です。先に実行してください：python src/run_artificial_batch.py --pref "XX,YY"）`
   - 2行目の割合の分母は、人工地形の2ファイルがそろっている県の碑・比較地点の数。分母が0なら 0.0%
   - 3行目：人工地形の2ファイルがそろっている県ごとに、`人工地形_範囲外_碑` と `地形分類_データなし_碑`、`人工地形_範囲外_比較地点` と `地形分類_データなし_比較地点` を比べる。
     - すべての県で両方とも同じなら：`人工地形の範囲外と地形分類（詳細版）のデータなし：一致（碑 a・比較地点 b）`（a・b は2行目の範囲外の数）
     - 違う県があれば：`人工地形の範囲外と地形分類（詳細版）のデータなし：不一致の県があります：県名（XX）、県名（YY）（先に実行してください：python src/run_artificial_batch.py --pref "XX,YY"）`（県コード順）
   - そろっている県が1つもないときは、2・3行目を出さず1行目だけを出す
5. tests/test_count_missing.py にテスト関数を足し、`python -m pytest -q` を実行する（tmp_path に偽の data/processed を作る）。最低限：
   (a) 人工地形の2ファイルがある県で、4列の数（範囲外・取得不可。取得済・人工地形なしは数えない）と全国の合計が正しい
   (b) 人工地形のファイルがない県：結果の行に入る、missing_prefs に入らない、4列が空欄、全国の合計に入らない、画面の1行目に県名と run_artificial_batch.py の案内が出る
   (c) 画面の3行が地域版の行の直後にこの順で出る。範囲外と詳細版のデータなしの数が違う県があると、3行目が「不一致の県があります」と県名・案内になる
   (d) 出力の CSV が BOM 付き・LF（\r を含まない）、列が COLUMNS（30列）と同じ順
   (e) 実データでの照合（data/processed に47県の12ファイル〔既存の8＋地域版2＋人工地形2〕がそろっているときだけ。なければ pytest.skip。output/ には書かない。集計の関数を直接呼ぶ）：
       全国の 人工地形_範囲外 碑929・比較地点4,890、人工地形_取得不可 0・0。徳島（36）は 11・62・0・0、岩手（03）は 149・754・0・0、東京（13）は 4・16・0・0。
       47県すべてで 人工地形_範囲外 と 地形分類_データなし が碑・比較地点とも同じ。既存の26列の全国の値は既存のテストと同じ
6. `python src/count_missing.py` を実行する（output/missing_counts.csv が書き換わる）。
7. コメントは日本語。count_artificial の docstring に「範囲外は詳細版のデータなしと同じ数になるはず」と書く。
