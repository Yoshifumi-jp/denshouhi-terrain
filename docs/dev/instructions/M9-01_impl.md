## 1. 県指定の解釈（新しい関数）
`parse_pref_arg(pref_arg)` を追加する。
- 戻り値：`"all"`、または県コードの文字列のリスト（重複を除き、小さい順に並べる）
- 区切りはカンマ。各要素の前後の空白は取り除く（`"28, 03,20,03"` → `["03", "20", "28"]`）
- 次の場合は ValueError（メッセージは下の形）
  - 空文字・空の要素だけ（`""`、`","`）
  - PREFECTURES にない値（`"99"`、1桁の `"3"`、`"abc"`）
  - all とほかの県を混ぜたもの（`"all,36"`）
- エラーメッセージの形（使えない値をカンマ区切りで並べる。空のときは「（空）」）：
  `エラー: --pref に使えない県コードがあります: 99, 3（01〜47 の2桁をカンマ区切りで、または all を指定してください）`

## 2. main の動き
- `main(argv=None, output_dir=None)` とし、引数なしで呼んだときは今と同じくコマンドラインの値と data/processed/ を使う（テストから出力先を変えられるようにするため）。`--raw` の扱い・データ取得日の判定は今のまま。
- parse_pref_arg の ValueError は、メッセージを表示して終了コード1で終わる。

### 2-1 1県（例 `--pref 36`）
今と同じ処理・同じ表示（下の 2-4 のパス表示の変更だけ）。

### 2-2 複数県（例 `--pref 03,20,28`）
- CSV の読み込み・検査・災害種別の分解は1回だけ行う
- 県コードの小さい順に、県ごとに「絞り込み → check_locations → save_dataframe → print_summary」を行う。県と県の間に空行を1行入れる
- 該当する碑が0基の県は、ファイルを作らず `警告: <県名>(<県コード>) の碑は0基のため、ファイルを作りません` と表示して次へ進む
- 最後に1行：`対象の県数: 3県　合計: 377基`（県数はファイルを作った県の数。「　」は全角スペース）

### 2-3 全国（`--pref all`）
- 今の動き（monuments_all.csv の保存と、全国のまとめ表示）は変えない
- それに続けて、データにあるすべての県について monuments_{県コード}.csv を作る（check_locations も県ごとに行う。print_summary は県ごとには出さない）
- データの中に PREFECTURES にない県コードがあれば `警告: 都道府県一覧にない県コードがあります: <コード>（<件数>件）` と表示し、そのファイルは作らない
- 最後に次の2行を表示する
  - `県別のファイル: 47件`
  - `全国の基数と県別ファイルの合計: 一致（2481基）`（合わないときは `全国の基数と県別ファイルの合計: 不一致（全国 <n>基、県別の合計 <m>基）`）

### 2-4 パスの表示
print_summary の「保存先のファイル名」は、プロジェクトのルートからの相対パスを `/` 区切りで表示する（例 `data/processed/monuments_36.csv`）。output_dir がプロジェクトの外（テストの一時フォルダなど）のときはファイル名だけを表示する。
