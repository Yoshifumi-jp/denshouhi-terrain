## やること（手順）

### 1. 人工地形の読み込み（碑の一覧用）
1. `load_monument_list(data_dir)` で、地域版の結合の直後に、県ごとに `data_dir / f"landform_artificial_{pref}.csv"` があれば `ID`・`人工地形名`・`人工地形_状態` の3列を ID で左結合する。無い県は2列を空文字にする（地域版と同じ書き方）。
2. 新しい列 `人工地形_表示` を作る：
   - 人工地形_状態＝取得済 かつ 名前が空でない → 人工地形名（例：干拓地）
   - 人工地形_状態＝人工地形なし → `人工地形なし`
   - 人工地形_状態＝範囲外 → `範囲外`
   - 人工地形_状態＝取得不可 → `取得不可`
   - それ以外（ファイルが無い県・空・取得済で名前が空）→ `データなし`
3. ファイルが無い県があっても止めない。最後のまとめ表示の前に、無い県がある場合だけ次の1行を出す（問題なし・問題ありの両方の箇所。地域版の案内の行の直後）：
   `人工地形のファイルがない都道府県：<県コードを「、」でつなぐ>（一覧の人工地形はデータなし）`

### 2. 碑の一覧（列と絞り込み）
1. 一覧の表の見出しで `<th>地形分類（地域版）</th>` の直後に `<th>人工地形</th>` を足す（10列になる）。
2. 最初の200行（initial_rows）にも、地域版の td の直後に人工地形_表示の td を足す（html エスケープ）。
3. MONUMENTS の各要素の**最後（12番目、添字11）**に人工地形_表示を足す。既存の添字0〜10の意味は変えない。JS のコメント `// mon = [...]` の末尾にも「人工地形」を足す。
4. JS の行の作成で、地域版の td（mon[10]）の直後に `mon[11]` の td を足す（textContent で入れる）。
5. 絞り込みの「地形分類（地域版）：」の filter-item の直後に、次の filter-item を足す：
   - `<label for="f-landform-artificial">人工地形：</label>`、`<select id="f-landform-artificial">`、先頭は `<option value="">すべて</option>`
   - 選択肢は関数 `landform_artificial_options(df)` を新設して作る（今の landform_options・landform_region_options は変えない）。決まり：人工地形の名前（人工地形なし・範囲外・取得不可・データなし以外）を多い順・同数は名前順に並べ、その後に `人工地形なし`、`範囲外`、`取得不可`、`データなし` の順で、**一覧に1基以上あるものだけ**を付ける。
6. updateMonumentList で `f-landform-artificial` の値が空でなければ `mon[11]` と一致する碑だけにする。change のイベントも足す。

### 3. 人工地形の集計表（2つ）
地域版の節（landform_region_section_html）の**直後**に、次の2つの節を足す。どちらも今の表と同じ `<div class="table-container"><table>…` の形で、割合は今の表と同じく ×100 して小数1桁＋%（`f"{float(x) * 100:.1f}%"`）。

**表A　人工地形（全碑・全種別）**
- 見出し `<h2>地形分類（人工地形・全碑・全種別）</h2>`
- 表：5列（人工地形／碑の数／碑の割合／まわりの数／まわりの割合）。中身は `output/landform_artificial_all.csv` の 範囲＝全碑・災害種別＝全種別 の行（6行）。
- 並び：`人工地形なし` 以外を碑の数の多い順・同数は名前順、最後に `人工地形なし`。
- 表の下の p（2つ）：
  - `人工地形を調べていない碑 <C>基・まわりの地点 <D>点（地形分類の詳細版のデータがない範囲外など）は、割合の計算から除いています。`
  - `人工地形は自然地形の上に重なる情報です（例：もとは旧水部〔昔の海・湖・沼〕だった所を干拓・埋め立てた土地）。データを整備した時点の状態で、その後の造成・埋立は入っていません。`
- C＝47都道府県の `data_dir/landform_artificial_XX.csv` で 人工地形_状態 が「取得済」でも「人工地形なし」でもない碑の数（ファイルの無い県は monuments_XX.csv の碑の数を足す）。D＝`landform_artificial_points_XX.csv` の同じ条件の比較地点の数（ファイルの無い県は足さない）。summarize_artificial.py と同じ「取得済と人工地形なしだけを数える」に合わせる。

**表B　自然地形×人工地形（全碑）**
- 見出し `<h2>自然地形×人工地形（全碑）</h2>`
- 表：6列（自然地形／人工地形／碑の数／碑の割合／まわりの数／まわりの割合）。中身は `output/landform_artificial_cross_all.csv` の 範囲＝全碑 の行のうち、人工地形名が `人工地形なし` でなく、碑_件数が1以上の行だけ。
- 並び：碑の数の多い順、同数は自然地形名・人工地形名の順。
- 表の下の p（1つ）：
  - `人工地形のある碑を、自然地形との組み合わせで数えたものです（碑が0基の組み合わせは省いています）。割合は、同じ自然地形の碑（まわりの地点）のうち人工地形を調べたものに対する割合です。`
- 注の「注：」「出典：」で始まる行は CSV の末尾にあるので、範囲の列で絞れば表に入らない（念のため 範囲＝全碑 で絞ること）。

**ファイルが無いとき**
- `landform_artificial_all.csv` が無いときは表Aの節を出さず、まとめ表示の前に `人工地形の集計（landform_artificial_all.csv）がないため、人工地形の表は出しません` の1行を出す。
- `landform_artificial_cross_all.csv` が無いときは表Bの節を出さず、まとめ表示の前に `自然地形×人工地形の集計（landform_artificial_cross_all.csv）がないため、組み合わせの表は出しません` の1行を出す。
- どちらも止めない。`required_files` には足さない。

### 4. ダウンロード・出典・注意書き

### 5. まとめ表示
「地域版の集計表：…」の行（問題なし・問題ありの両方の箇所）の直後に、次の2行を足す：
```
一覧の人工地形：<区分の数>区分（人工地形あり <F>基／人工地形なし <G>基／範囲外 <E>基）
人工地形の集計表：<表Aの行数>行／自然地形×人工地形の表：<表Bの行数>行
```
- 区分の数＝選択肢のうち 人工地形なし・範囲外・取得不可・データなし を除いた数。F＝それらの区分の碑の合計。G＝人工地形_表示が人工地形なしの碑の数。表を出さないときの行数は 0。
