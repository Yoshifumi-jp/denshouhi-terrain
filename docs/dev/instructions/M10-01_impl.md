## 目的（このテーマ1つ）
河川・海岸線までの距離を計算するときの平面直角座標系（距離をメートルで測るための座標。全国を19の「系」に分けたもの）を、
今の「徳島・千葉だけ登録」から **47都道府県すべて** に広げる。北海道・東京都・鹿児島県・沖縄県は1つの県に複数の系があるため、**碑の位置（北海道は市区町村）で系を選ぶ**。
隣接県の河川・海岸線を読む変更は次の指示書（M10-02）で行う。今回は行わない。

6. `select_zone(pref_code, lat, lon, muni_code=None)` → 系の番号（int）
   - pref_code が PREFECTURES にないとき：`ValueError(f"県コードが正しくありません: {pref_code}")`
   - "01"（北海道）：muni_code が None・空・"01" で始まらない5桁でないときは `ValueError(f"北海道の碑は市区町村コード（01で始まる5桁）が必要です: {muni_code}")`。ZONE11 にあれば 11、ZONE13 にあれば 13、それ以外は 12
   - "13"（東京都）：`lat < 28.0` のとき、`lon < 140.5` なら 18、`lon >= 143.0` なら 19、それ以外は 14。`lat >= 28.0` なら 9
   - "47"（沖縄県）：`lon < 126.0` なら 16、`lon >= 130.0` なら 17、それ以外は 15
   - "46"（鹿児島県）：`27.0 <= lat <= 32.0` かつ `lon >= 128.3`（東経128度18分）かつ（`lon <= 130.0` または（`lat < 29.0` かつ `lon <= 130.0 + 13/60`））なら 1、それ以外は 2
     - コメントに書くこと：告示の I系の区域「北緯32度・27度、東経128度18分・130度で囲む区域内の島（奄美群島は東経130度13分まで）」を緯度経度で判定している。奄美群島は北緯29度より南。九州本土には東経130度より西の陸地はない（推測を含む。最西端の野間岬付近は東経130.1度台）
   - それ以外：`PREF_ZONE[pref_code]`
7. `select_epsg(pref_code, lat, lon, muni_code=None)` → `JPC_EPSG[select_zone(...)]`

## 2. src/add_river_coast.py（変更）
1. import を `from src.prefectures import PREFECTURES, JPC_EPSG, ZONE_NAMES, select_epsg`（except 側も同じ）に変える。`EPSG_CODES` は使わない
2. 新しい関数 `make_epsg_by_id(target_df, pref_code, target, monuments_df=None)` → 辞書 {ID: EPSG}
   - target が "monuments"：各行の `select_epsg(pref_code, float(緯度), float(経度), str(市区町村コード).zfill(5))`
   - target が "points"：比較地点は**元の碑と同じ系**にする（碑と比較地点を同じ物差しで比べるため）。monuments_df から上と同じ方法で碑の {ID: EPSG} を作り、各比較地点の `元の碑ID` で引く。見つからないときは `ValueError(f"比較地点の元の碑が見つかりません: {比較地点のID}")`
3. `process_river_coast` の引数 `epsg_code` は、**int（全件同じ系。今までどおり）または dict {ID: EPSG}** を受け付ける
   - int のときは、全IDにその値を割り当てた dict にしてから処理する
   - dict に載っていない ID があれば `ValueError(f"座標系が決まっていない碑があります: {ID}")`
   - 河川・海岸線のシェープファイルは**1回だけ読み**、EPSG ごと（小さい順）に、その EPSG の碑だけを取り出して、碑・河川（名前のある河川を含む）・海岸線を `to_crs` してから、**今の1件ごとの処理をそのまま**行う。距離・標高の取り方・状態の決め方・表示の文は変えない
   - 1件ごとの進捗表示の番号（`{idx+1}/{total}`）は今と同じく元の表の行番号を使う（徳島の表示が変わらないように）
   - 出力 CSV の列・並び順（ID 順）は変えない。**座標系の列は足さない**（第1版の出力と同じにするため）
   - 中断（Ctrl+C）の扱いは今と同じ
4. まとめ表示：「基数: …」の行の直後に次を足す（系の番号の小さい順。件数0の系は出さない）
   ```
   座標系の内訳:
     第IV系（EPSG:6672）: 71
   ```
5. main()：
   - 「この県の座標系は未設定です」の判定を削除する
   - 碑・比較地点の CSV を読むとき `dtype={'ID': str, '市区町村コード': str}` とする（比較地点の CSV に市区町村コードの列はないが、pandas は無い列の指定を無視するので同じ書き方でよい。念のため動作を確かめること）
   - target が points のときは `data/processed/monuments_{県}.csv` も読む。無ければ `先に python src/load_monuments.py --pref {県} を実行してください` と出して終了（コード1）
   - `make_epsg_by_id` で dict を作り、`process_river_coast` に渡す。ValueError のときは `エラー: {内容}` と出して終了（コード1）
