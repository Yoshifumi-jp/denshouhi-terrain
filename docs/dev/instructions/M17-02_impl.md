# 指示書 M17-02（実装）　作成日：2026-10-16

最初に AGENTS.md を読んでから作業してください。

## 目的（このテーマ1つ）
全国ページ（docs/index.html を作る src/build_national.py）に地形分類の地域版を反映する：碑の一覧に地域版の列と絞り込み、地域版の集計表、ダウンロード、注意書き。
詳細版と地域版は混ぜない（今の「地形分類」の列・絞り込み・表はそのまま。地域版は別の列・別の絞り込み・別の表）。

## 対象ファイル
- src/build_national.py（変更）
- tests/test_build_national.py（テスト関数を3つ追加。既存のテストは変えない）

## やること（手順）

### 1. 地域版の読み込み（碑の一覧用）
1. `load_monument_list(data_dir)` で、県ごとに `data_dir / f"landform_region_{pref}.csv"` があれば `ID`・`地域版_地形分類名`・`地域版_状態` の3列を ID で左結合し、新しい列 `地域版_表示` を作る：
   - 地域版_状態＝取得済（地域版）かつ名前が空でない → 地域版_地形分類名（例：低地）
   - 地域版_状態＝取得済（広域版）かつ名前が空でない → `<名前>（広域版）`
   - それ以外・ファイルが無い県 → `データなし`
2. ファイルが無い県があっても止めない。build_national の最後のまとめ表示の前に、無い県がある場合だけ次の1行を出す：
   `地域版のファイルがない都道府県：<県コードを「、」でつなぐ>（一覧の地域版はデータなし）`
3. 地域版の「データなし」の碑の数（地域版_表示＝データなし）を数える（下の注意書き・表示で使う）。

### 2. 碑の一覧（列と絞り込み）
1. 一覧の表の見出しを `<th>地形分類</th>` の直後に `<th>地形分類（地域版）</th>` を足す（9列になる）。
2. 最初の200行（initial_rows）にも、地形分類の td の直後に地域版_表示の td を足す（html エスケープ）。
3. MONUMENTS の各要素の**最後（11番目、添字10）**に地域版_表示を足す。既存の添字0〜9の意味は変えない。JS のコメント `// mon = [...]` も末尾に「地形分類（地域版）」を足す。
4. JS の行の作成で、地形分類の td の直後に `mon[10]` の td を足す（textContent で入れる）。
5. 絞り込みの「地形分類：」の filter-item の直後に、次の filter-item を足す：
   - `<label for="f-landform-region">地形分類（地域版）：</label>`、`<select id="f-landform-region">`、先頭は `<option value="">すべて</option>`
   - 選択肢は地域版_表示の値を、多い順・同数は名前順、最後に「データなし」（今の landform_options と同じ決まり。関数を作るなら `landform_region_options(df)` とし、今の landform_options は変えない）
6. updateMonumentList で `f-landform-region` の値が空でなければ `mon[10]` と一致する碑だけにする。change のイベントも足す。

### 3. 地域版の集計表
1. 「地形分類（全碑・全種別）」の表と、その下の注の p の**直後**に次の節を足す：
   - 見出し `<h2>地形分類（地域版・全碑・全種別）</h2>`
   - 表：今の地形分類の表と同じ5列（地形分類／碑の数／碑の割合／まわりの数／まわりの割合）。中身は `output/landform_region_all.csv` の 範囲＝全碑・災害種別＝全種別 の行。並びは碑の数の多い順、同数は名前順。割合は今の表と同じく ×100 して小数1桁＋%。
   - 表の下の p（2つ）：
     - `地域版で値が取れなかった碑 <A>基・まわりの地点 <B>点は、割合の計算から除いています。`
     - `地域版は詳細版より分類が粗い（中分類12種）ため、碑とまわりの地点（100m〜2,000m）が同じ分類になりやすく、差が出にくくなります。`
   - A＝47都道府県の landform_region_XX.csv で 地域版_状態 が「取得済（地域版）」でない碑の数、B＝同じく landform_region_points_XX.csv の比較地点の数（summarize_region.py と同じ「取得済（地域版）だけを数える」に合わせる）。
2. `output/landform_region_all.csv` が無いときは、この節を出さず、まとめ表示の前に `地域版の集計（landform_region_all.csv）がないため、地域版の表は出しません` の1行を出す。止めない。
3. `required_files` には足さない。

### 4. ダウンロード・注意書き
1. landform_region_all.csv があるときは `docs/data/landform_region_all.csv` にコピーし（作成したファイルに入れ、公開前チェックの対象にする）、「データのダウンロード」の `地形分類` の行の直後に `<li><a href="data/landform_region_all.csv">地形分類（地域版）</a></li>` を足す。無いときはコピーもリンクもしない。
2. 「ご利用上の注意」の「地形分類（自然地形）のデータは整備された地域が限られ…」の li の直後に、次の li を足す：
   `地形分類（地域版）は、詳細版のない地域も含めて全国の碑に付けたものです（値が取れなかった碑 <A>基）。詳細版とは分類の細かさが違うため、別の列・別の表にしています。`

### 5. まとめ表示
「一覧の地形分類：…」の行（問題なし・問題ありの両方の箇所）の直後に、次の2行を足す：
```
一覧の地形分類（地域版）：<区分の数>区分＋データなし（データなし <A>基）
地域版の集計表：<行数>行
```
- 区分の数＝選択肢の数−1。行数＝地域版の表の行数（表を出さないときは 0）。

### 6. テスト（追加のみ）
tests/test_build_national.py の既存の作り方（一時フォルダに小さな CSV を置く）に合わせて3つ：
- `test_national_region_column_and_filter`：2県分の地域版ファイルを置く（1基は 取得済（地域版）・低地、1基は データなし、1基は 取得済（広域版）・山地・丘陵 など）→ index.html に `地形分類（地域版）` の見出しと `id="f-landform-region"` があり、選択肢が決まりどおりの順で最後が データなし、MONUMENTS の要素の添字10が期待どおり（`山地・丘陵（広域版）` を含む）。
- `test_national_region_table`：landform_region_all.csv を置く → 地域版の表の見出し、並び（碑の数の多い順）、割合の表示（例 0.535 → 53.5%）、注の数 A・B、ダウンロードのリンク、docs/data へのコピー。
- `test_national_region_missing`：地域版のファイルを1つも置かない → ページは作られ、地域版の表とリンクは無く、2つの案内の行が表示される。一覧の地域版の列はすべて データなし。
