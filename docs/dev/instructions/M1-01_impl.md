# 指示書 M1-01（実装）　作成日：2026-09-27

最初に AGENTS.md を読んでから作業してください。

## 目的（このテーマ1つ）
Python の開発環境を整え、国土地理院の自然災害伝承碑CSVを読み込んで、指定した都道府県の碑を「災害種別ごとの印（0/1）」付きで data/processed/ に保存するプログラムを作る。

## 対象ファイル（新規作成）
- requirements.txt
- src/prefectures.py … 都道府県コード（01〜47）と都道府県名の対応表
- src/load_monuments.py … 読み込み・整形・保存・件数表示の本体
- tests/data/sample.csv … テスト用の小さな架空データ（5〜8行）
- tests/test_load_monuments.py … 自動テスト

## やること（手順）
1. 環境
   - `python -m venv .venv` で仮想環境を作り、requirements.txt に `pandas` と `pytest` を書いてインストールする。
   - 使ったPythonのバージョンと、環境を作るコマンド（Windowsの PowerShell 用）を完了報告に書く。
2. 元データの読み込み（src/load_monuments.py）
   - 文字コードは UTF-8（BOM付き）。全列を文字列として読む（ID の先頭の0が消えないように）。
   - 元データの場所は、引数 `--raw` で指定できるようにする。省略時は data/raw/ の中で日付が最も新しいフォルダの CSV を使う。
   - 必須の列：ID, 碑名, 建立年, 所在地, 災害名, 災害種別, 伝承内容, 緯度, 経度, 公開日, 修正等公開日, 制限事項
     1列でも欠けていたら、欠けている列名を日本語で表示して処理を止める（誤った結果を作らないため）。
   - ID が「数字5桁-数字3桁」の形でない行があれば、その ID を表示して処理を止める。
3. 県の指定
   - 引数 `--pref` に県コード（例：36）または `all` を指定する。県コードは ID の先頭2桁で判定する。
   - 01〜47 と all 以外が指定されたら、エラーメッセージを出して止める。
   - 所在地の先頭が、県コードに対応する都道府県名で始まらない行は「警告」として ID を表示する（処理は続ける）。
4. 列の追加
   - `県コード`（ID先頭2桁）、`市区町村コード`（ID先頭5桁）、`データ取得日`（元データのフォルダ名。例 2026-09-24）
   - 災害種別を「・」で分けて、次の7列に 1／0 を入れる：
     `種別_洪水` `種別_地震` `種別_津波` `種別_土砂災害` `種別_高潮` `種別_火山災害` `種別_その他`
   - 7種類以外の種別が出てきたら、その種別名と件数を「警告」として表示する（処理は続ける）。
5. 保存
   - data/processed/monuments_<県コード>.csv（all のときは monuments_all.csv）に、UTF-8（BOM付き、Excelで文字化けしない形）で保存する。
   - 元の列はすべて残し、追加した列を後ろに付ける。ID の昇順に並べる。
6. 表示（実行したときに画面に出すもの）
   - データ取得日、対象の県名、基数、災害種別ごとの基数、保存先のファイル名
   - `all` のときは、これに加えて都道府県ごとの基数の一覧を表示する。
   - 表示はすべて日本語。
7. 処理の中身は関数に分ける（読み込み／検査／種別の分解／県の絞り込み／保存）。テストから個別に呼べるようにする。
8. 自動テスト（tests/test_load_monuments.py）
   - tests/data/sample.csv（架空データ）を使い、少なくとも次を確かめる：
     a. 「地震・津波」の行で 種別_地震=1、種別_津波=1、それ以外の種別=0 になる
     b. 県コードで絞り込んだ件数が正しい
     c. 必須の列が欠けたCSVで、処理が止まる（例外になる）
     d. ID の形が不正な行があると処理が止まる
     e. 保存したCSVを読み直して、日本語が文字化けせず、ID の先頭の0が残っている
   - さらに、実データ data/raw/2026-09-24/denshouhi_20260924.csv があるときだけ動くテストを1つ置く：
     徳島(36)=71基、千葉(12)=52基、全国=2481基 であること
   - `python -m pytest` で全件合格すること。

## やらないこと

- data/raw/ の元データの変更
- 標高・地形・地図に関する処理（M2 以降で行う）
- pandas と pytest 以外のライブラリの追加
- git commit、git push
