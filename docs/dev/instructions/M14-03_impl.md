2. `short_name(pref)`：PREFECTURES の名前から末尾の「都・府・県」を1字だけ取る（北海道はそのまま）。例：東京都→東京、京都府→京都、大阪府→大阪、神奈川県→神奈川、鹿児島県→鹿児島
3. `COLOR_CLASSES`：色分けの区分（下限・上限・表示名・背景色・文字色）。碑の数と災害種別で同じ区分を使う

| 区分 | 背景色 | 文字色 |
|---|---|---|
| 0 | #f2f2f2 | #333333 |
| 1〜9 | #deebf7 | #333333 |
| 10〜19 | #9ecae1 | #333333 |
| 20〜49 | #6baed6 | #333333 |
| 50〜99 | #3182bd | #ffffff |
| 100以上 | #08519c | #ffffff |

   `color_class(n)` は n（0以上の整数）の区分の表示名を返す（0→"0"、9→"1〜9"、10→"10〜19"、49→"20〜49"、50→"50〜99"、99→"50〜99"、100→"100以上"）
4. `required_files(output_dir, data_dir, site_dir)`：上の表の output の CSV 6つ＋グラフ2つ＋data/processed の 47×3 ファイル＋ docs/pref_01.html〜pref_47.html（県別ページへのリンク先がないページを作らないため）
5. `load_monument_list(data_dir)`：47県の monuments と landform を ID で結合し、県コード・ID の順に並べた表を返す。地形分類名が空の碑は「データなし」
6. `landform_options(df)`：一覧の絞り込みの地形分類の選択肢。碑の数の多い順、同数は名前順（Python の文字列の並び。M13_review-1 No.2）、最後に「データなし」を1つ。

### 2. docs/index.html の中身（上から順に）
既存の県別ページ（build_site.py）と同じ見た目の基本スタイル（body の max-width 800px、table、.table-container の横スクロール、h2 の下線）を使う。外部の CSS・JavaScript・フォントは読み込まない（1つのファイルで完結）。

1. `<title>自然災害伝承碑と地形（全国）</title>`、`<h1>自然災害伝承碑と地形（全国）</h1>`
2. 説明：`伝承碑データ取得日：2026-09-24　碑の数：2,481基（47都道府県）`（日付は monuments のデータ取得日の最大値、碑の数は一覧の行数）と、県別ページと同じ趣旨の1段落（国土地理院の自然災害伝承碑に碑ごとの地形を付け、碑のまわり（100m〜2,000m）の地点と比べた結果。地形との相関であり、災害の予測・安全の保証ではない）
3. **都道府県の色分け地図**（h2）
   - 切り替え `<select id="map-type">`：「碑の数」「洪水」「地震」「津波」「土砂災害」「高潮」「火山災害」「その他」（値は pref_counts_all の 碑_数・種別_〇〇）
   - タイル：CSS grid（14列）。各タイルは `<a href="pref_XX.html">` で、短い県名と件数の2行。色は COLOR_CLASSES。title 属性に「岩手県：碑の数 163基」のような文
   - 地図を囲む div は `overflow-x: auto`、grid の min-width は 480px（スマホでは地図だけ横にずらせる。ページ全体は横にはみ出さない）。地図の下に `スマホでは地図を横にずらして見られます。県の四角を押すと、その県のページに移ります。` の1行
   - 凡例：6区分の色見本と表示名（「0」「1〜9」…「100以上」）と単位（基）
   - 切り替えたときは JavaScript で各タイルの件数・色・title と、凡例の見出し（例：「津波の碑の数」）を変える。最初の表示（JavaScript なしでも見える状態）は「碑の数」
   - 県ごとの数は Python 側で JSON にしてページに埋め込む
4. **都道府県別の件数**（h2）：pref_counts_all の47行＋全国の行の表。列：都道府県（pref_XX.html へのリンク）／地図（map_XX.html へのリンク、文字は「地図」）／碑の数／移転碑／洪水／地震／津波／土砂災害／高潮／火山災害／その他。表の下に「1基が複数の災害種別を持つため、種別ごとの合計は碑の数より多くなります。」
5. **碑の一覧（絞り込み）**（h2）
   - `<select id="f-pref">`（「全国」＋47都道府県、県コード順）、`<select id="f-type">`（「すべて」＋7種別）、`<select id="f-landform">`（「すべて」＋ landform_options の順）
   - 件数の表示 `<p id="f-count">該当：2,481基</p>`（3桁区切り）
   - 表の列：ID／碑名／都道府県（pref_XX.html へのリンク）／所在地／災害種別／地形分類／建立年／地図（地理院地図 `https://maps.gsi.go.jp/#16/<緯度>/<経度>/` を新しいタブで、文字は「地理院地図」）
   - 表示は最大200行。該当が200を超えるときは表の下に `該当が多いため、最初の200基を表示しています。都道府県や災害種別で絞り込んでください。`
   - 災害種別の絞り込みは種別_〇〇＝1 の碑（複数種別の碑はそれぞれの種別に入る）
   - データは Python 側で JSON にして `<script>` に埋め込む（1基＝配列 [ID, 碑名, 県コード, 所在地, 災害種別, 地形分類, 建立年, 緯度, 経度, 種別のリスト]）。`json.dumps(..., ensure_ascii=False)` の後、`</` を `<\/` に置き換えてから埋め込む
   - **表に入れるときは textContent・createElement を使い、innerHTML にデータを入れない**（碑名・所在地などをそのまま HTML として解釈させないため）
6. **碑とまわりの比較（全碑・全種別）**（h2）：県別ページと同じ表（指標／碑の中央値／まわりの中央値／差の中央値／碑の方が大きい割合）。指標名・値・割合の書き方は build_site.py の summary の表と同じ（例：`標高(m)`、割合は `int(round(割合*100))%`）
7. **ハザードマップの想定区域との重なり（全碑・全種別）**（h2）：県別ページと同じ表（ハザード／碑：区域内／まわり：区域内／碑：浸水深3m以上／まわり：浸水深3m以上）。書き方は build_site.py の calc_ratio と同じ（例：`35%（860／2481基）`、土砂災害の3m以上は「—」）。表の下に「想定区域との重なりを示すもので、危険度の判定ではありません。」
8. **地形分類（全碑・全種別）**（h2）：列：地形分類／碑の数／碑の割合／まわりの数／まわりの割合。並びは碑の数の多い順・同数は名前順。割合は `碑_割合×100` を小数1桁＋%（例：29.1%）。表の下に `地形分類のデータがない碑 929基・まわりの地点 4,890点は、割合の計算から除いています。`（数は landform・landform_points の「データなし」を数える）
9. **グラフ**（h2）：`fig/years_all.png`（見出し「災害の発生年代と碑の建立年代」）、`fig/pref_counts_all.png`（見出し「都道府県別の碑の数」）
10. **データのダウンロード（CSV、Excel で開けます）**（h2）：6つの CSV へのリンク（集計表 summary_all／ハザードマップの想定区域との重なり hazard_summary_all／地形分類 landform_all／移転碑の一覧 relocated_all／都道府県別の件数 pref_counts_all／年代別の碑の数 years_all）と、県別の CSV は各県のページにある旨の1行
11. **出典**（h2）：build_site.py の出典の箇条書きから「背景地図」の行を除いたもの（全国ページには背景地図がない）
12. **ご利用上の注意**（h2）：build_site.py の注意3項目に、次の4項目を足す
    - `移転碑（伝承内容に「移転」「移設」を含む碑、全国102基）は文字で機械的に選んでいるため、集団移転や施設の移転を伝える碑など、碑そのものが移設されていないものも含まれます。`（102 は relocated_all の行数）
    - `ハザードマップの想定区域は、都道府県や河川ごとに公表の時期や想定が異なります。ハザードマップポータルサイトの配信データが最新の公表と一致しない場合もあります。` と、HAZARD_DATA_NOTES の各項目を「徳島県：…」のように県名を付けて
    - `地形分類（自然地形）のデータは整備された地域が限られ、全国の碑の 37.4%（929基）はデータがありません。`（割合は 929÷2,481 を小数1桁）
    - `1基の碑が複数の災害種別を持つことがあります。`
13. 最下部に `<p>県別のページ：<a href="pref_01.html">北海道</a>　…</p>`（47県のリンクを全角スペースでつなぐ）
