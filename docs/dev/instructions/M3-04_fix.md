# 指示書 M3-04（修正）　作成日：2026-10-01

最初に AGENTS.md を読んでから作業してください。

## 目的（このテーマ1つ）
add_river_coast のテストを指示書 M3-03 のとおりに直し、あわせて同じファイルの軽微な整理を行う。**計算・出力の中身は変えない。**

## 対象ファイル
- tests/test_add_river_coast.py
- src/add_river_coast.py（import・変数・警告の整理だけ）

## 不具合の内容
- 起きていること：test_height_diff の場合1・2で、問い合わせ関数が種別「10m」を返すように変わり、期待する河川_状態が「取得済（参考値：10mメッシュ）」になっている。指示書 M3-03 の 9 では「期待値は変えない」としていた。このため、process_river_coast を通した「取得済」の経路が検査されていない
- 本来の動き：場合1・2は、精しい値（種別「5m（レーザ）」）が返り、河川_状態「取得済」になることを確かめる
- 原因の見立て（Claudeのソース確認 M3_review-2 より）：tests/test_add_river_coast.py 120–126行の parametrize の値

## やること（手順）
1. test_height_diff の parametrize を次の5つの場合にする（座標は今の 34.005 のままでよい）。
   | 場合 | 碑の標高 | 問い合わせ関数の返す値 | 期待する 河川との高さの差_m | 期待する 河川_状態 |
   |---|---|---|---|---|
   | 1 | 10.0 | {"elevation": 3.5, "hsrc": "5m（レーザ）"} | 6.5 | 取得済 |
   | 2 | 2.0 | {"elevation": 5.0, "hsrc": "5m（レーザ）"} | −3.0 | 取得済 |
   | 3 | 空欄（NaN） | {"elevation": 3.5, "hsrc": "5m（レーザ）"} | 空欄 | 高さの差 取得不可（碑の標高なし） |
   | 4 | 10.0 | {"elevation": "-----", "hsrc": ""} | 空欄 | 高さの差 取得不可（河川の標高なし） |
   | 5 | 10.0 | 毎回例外（Exception）を出す | 空欄 | 高さの差 取得不可（通信エラー） |
   - 場合1・2では、あわせて「河川側の標高_m」が問い合わせ関数の値（3.5／5.0）、「河川側の標高_種別」が「5m（レーザ）」であることを確かめる
   - 場合4・5で「河川側の標高_m」が空欄であることの確認は今のまま残す
2. test_height_diff に、場合6を追加する：碑の標高 10.0、問い合わせ関数が {"elevation": 3.5, "hsrc": "10m"} を返す → 高さの差 6.5、河川_状態「取得済（参考値：10mメッシュ）」（今の場合1が確かめていた内容を残すため）
3. test_out_of_range に、対象外の碑でも「最寄り河川名」が「TestRiver」、「河川までの距離_m」が1000より大きい数値、「河川最近点_緯度」「河川最近点_経度」が空欄でないことの確認を追加する
4. src/add_river_coast.py の整理（動きは変えない）
   - 使っていない `import glob` を消す（math は使っているので残す）
   - calc_distance_and_nearest の `p1, p2 = nearest_points(...)` の p1 を `_` にする
   - `warnings.filterwarnings("ignore")` を消す。消した後に pytest や本体の実行で警告が出た場合は、その警告だけを対象にした抑制（`warnings.filterwarnings("ignore", message=..., category=...)`）にとどめ、何の警告かを報告に書く。警告を消す必要がなければ `import warnings` も消す
5. 報告書を書く前に `.venv\Scripts\python -m pytest` を実行し、全件合格を確かめる
