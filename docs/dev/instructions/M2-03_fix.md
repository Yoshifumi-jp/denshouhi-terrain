## 目的（このテーマ1つ）
キャッシュの読み込みと列の型の扱いを、pandas（表データを扱うライブラリ）のバージョンに左右されない形に直す。
知人が別の時期に環境を作っても同じように動くようにするため。

## 対象ファイル
- src/add_elevation.py
- tests/test_add_elevation.py
- requirements.txt

## やること（手順）
1. キャッシュを読むとき・キャッシュが空のときのどちらでも、「緯度」「経度」の列を必ず数値（float）として扱う。
   （今は空のキャッシュの列が文字型になり、pandas 2.x では `.round(6)` で TypeError になる：src/add_elevation.py 60行、145〜151行）
2. キャッシュファイルが壊れていて読めないときは、黙って空として扱わず、
   「警告: キャッシュファイル <パス> を読めません。ファイルを確認してください。」と表示して処理を止める。
3. requirements.txt に、動作を確かめた範囲のバージョンを書く（例：`pandas>=2.2,<4`、`requests>=2.31,<3`、`pytest>=8`）。
   pandas 2.2 以上・3.x のどちらでも動く書き方にすること。
4. テストを追加する：
   a. キャッシュファイルがない状態で1基を処理すると、問い合わせ5回で「取得済」になる（初回実行の確認）
   b. 「-----」（データなし）を含むキャッシュを読み込んでも、数値の地点は数値として正しく使われる
   c. 壊れたキャッシュファイル（例：中身が1行のでたらめな文字）を置いて実行すると、処理が止まる
5. `python -m pytest` で全件合格すること。
