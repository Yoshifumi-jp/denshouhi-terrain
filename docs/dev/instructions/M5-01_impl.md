## 目的（このテーマ1つ）
徳島県の伝承碑71基を、災害種別で色分けした地図 HTML（1ファイル）にする。碑をクリックすると、その碑の地形の診断結果（標高・まわりとの高さの比較・地形分類・河川・海岸）と伝承内容が出る。
地図には出典・加工の旨・免責文を表示する。PC とスマホのブラウザで開けること。
ネットへの問い合わせは行わない（data/processed/ の CSV だけを読む。背景地図はブラウザが表示時に地理院タイルを読む）。

## 色分け（主な種別）
1基が複数の種別を持つため、次の優先順で最初に当てはまる種別を「主な種別」とし、その色で塗る。
優先順と色（色覚の違いに配慮した配色）：

| 優先 | 主な種別 | 色 |
|---|---|---|
| 1 | 津波 | #0072B2 |
| 2 | 高潮 | #56B4E9 |
| 3 | 洪水 | #009E73 |
| 4 | 土砂災害 | #E69F00 |
| 5 | 火山災害 | #D55E00 |
| 6 | 地震 | #CC79A7 |
| 7 | その他 | #7F7F7F |

- 判定は 種別_7列（1/0）で行う。どれも1でない碑は「その他」
- 徳島の見込み：津波49（地震・津波48＋高潮・地震・津波1）、洪水10、土砂災害8、地震2、高潮1、その他1＝71
- 印は円（CircleMarker、半径7、白い縁取り、塗りの不透明度0.85）

## 地図の作り
- 背景：地理院タイル 淡色地図 `https://cyberjapandata.gsi.go.jp/xyz/pale/{z}/{x}/{y}.png`（最大ズーム18）。帰属表示（attribution）は `<a href="https://maps.gsi.go.jp/development/ichiran.html" target="_blank" rel="noopener">地理院タイル</a>`
- 初期表示：全碑が入る範囲（fit_bounds）
- 主な種別ごとに FeatureGroup を作り、LayerControl（右上、折りたたみ）で表示／非表示を切り替えられるようにする。グループ名は「津波（49基）」のように件数付き。0基の種別は作らない
- 画面左下に固定の説明枠（HTML を地図に追加）。中身：
  1. 見出し「自然災害伝承碑と地形（徳島県）」と碑の数
  2. 凡例：色の丸＋主な種別名＋件数（0基の種別は出さない）。下に小さく「複数の種別を持つ碑は、津波＞高潮＞洪水＞土砂災害＞火山災害＞地震＞その他 の順で色を決めています」
  3. 常に見える1行の免責：「地形との相関を示すもので、災害の予測・安全の保証ではありません。」
  4. `<details><summary>出典・ご利用上の注意</summary>…</details>` の中に、下の「出典」「免責文」全文と「伝承碑データ取得日：2026-09-24」（monuments の データ取得日 列。値が複数あれば最新）
- スマホ対応：説明枠は最大幅 `min(320px, 90vw)`、最大高さ `50vh` で中をスクロール。文字は 13px 前後。`<meta name="viewport" content="width=device-width, initial-scale=1">` が入っていること（folium の既定で入るなら追加不要。報告で確認結果を書く）
- タイトル（`<title>`）：「自然災害伝承碑と地形（徳島県）」

## 出典（説明枠に表示。文言はこのまま）
- 自然災害伝承碑：国土地理院（https://www.gsi.go.jp/bousaichiri/denshouhi.html）
- 背景地図：地理院タイル（淡色地図）
- 標高・傾斜：国土地理院 標高API（標高タイル）から算出
- 地形分類：国土地理院 地形分類（自然地形）
- 河川・海岸線：「国土数値情報（河川データ、海岸線データ）」（国土交通省）
- 上記を加工して作成

## 免責文（説明枠に表示。文言はこのまま）
- 本地図の分析結果は、伝承碑の位置と地形との「相関」を示すもので、災害の発生を予測・保証するものではありません。防災上の判断には自治体のハザードマップをご利用ください。
- 碑の位置は被災した地点とは限りません（移設された碑もあります）。伝承碑の登録は市町村の申請によるもので、すべての碑を網羅しているわけではありません。

## 碑をクリックしたときの表示（ポップアップ。最大幅300px、中はスクロール可）
すべての文字列（碑名・所在地・災害名・伝承内容・河川名など CSV から来る値）は html.escape で無害化してから HTML に入れる。

1. 碑名（太字）と ID
2. 移転碑なら注記「※この碑は移設されています。今の位置は被災した地点とは限りません。」（extract_relocated と同じ判定）
3. 災害名／災害種別（元の文字列のまま）／建立年／所在地
4. 見出し「地形の診断」：
   - 標高：`X m（データ種別）`。取得状態が取得済でなければ その状態の文字列
   - まわりとの比較：その碑の比較地点のうち 取得状態＝取得済 の標高の中央値 M（n点）と比べる。差 D＝碑の標高−M（小数1桁に丸める）
     - |D| < 1.0 →「まわり（比較地点 n点の中央値 M m）とほぼ同じ高さ」
     - D ≧ 1.0 →「まわり（…）より D m 高い」、D ≦ −1.0 →「まわり（…）より |D| m 低い」
     - 使える比較地点が0点、または碑の標高が取得済でない →「比較地点なし」
   - 傾斜：`X 度`
   - 地形分類：地形分類名。地形分類_状態が取得済でない、またはコードが空なら「データなし」
   - 最寄り河川：`河川名（X m）`。最寄り河川名が「名称不明」で、名前のある最寄り河川がある場合は、続けて「／名前のある最寄り河川：名前（X m）」
   - 河川との高さの差：河川_状態が「取得済」→ `X m`、「取得済（参考値：10mメッシュ）」→ `X m（参考値）`、それ以外 → 河川_状態の文字列
   - 海岸までの距離：`X m`（海岸_状態が取得済でなければ その状態の文字列）
   - 数値が空（NaN）のときは「データなし」と出す。「nan」という文字を出さない
5. 伝承内容（全文）
6. リンク「地理院地図で見る」：`https://maps.gsi.go.jp/#17/{緯度}/{経度}/`（target="_blank" rel="noopener"）
7. 「危険」「安全」など判定の言葉は使わない

## 関数の分け方（テストしやすくするため。名前は目安）
- `main_type(row) -> str`：主な種別を返す
- `compare_with_surroundings(mon_elev, mon_status, point_elevs) -> str`：まわりとの比較の文を返す（point_elevs は取得済の標高のリスト）
- `fmt_value(value, unit, status=None, ok_status="取得済") -> str`：数値の表示（NaN・状態の扱い）
- `build_popup_html(row, comparison_text, is_relocated) -> str`
- `build_map(mon_df, pt_df, pref) -> folium.Map`
- `main()`：引数 `--pref`（必須）。県コードの確認・エラー文は summarize.py の main と同じ書き方。出力先は output/map_{pref}.html

## 出力
- output/map_36.html（utf-8）。同じ入力で2回実行して同じ内容になること（folium が要素 ID に乱数を使う場合は、報告にその旨を書けば一致しなくてよい。その場合も碑の数・中身が同じことを確かめる）
- まとめ表示：対象の県名／碑の数／主な種別ごとの件数／移転碑の数／まわりとの比較が「比較地点なし」の碑の ID／出力ファイル名

## テスト（tests/test_make_map.py。tmp_path の偽データで動かす。本物の data/ は読まない。ネットに接続しない）
- a. main_type：「地震・津波」の行→津波、「高潮・地震・津波」→津波、「地震」→地震、「洪水・土砂災害」→洪水、種別_7列がすべて0→その他
- b. compare_with_surroundings：碑 5.0、比較地点 [3.0, 10.0, 20.0] → 中央値 10.0、「5.0 m 低い」を含む／碑 12.0、比較地点 [10.0, 11.0] → 中央値 10.5、「1.5 m 高い」を含む／碑 10.4、比較地点 [10.0] →「ほぼ同じ」を含む／比較地点 [] →「比較地点なし」／碑の状態が取得済でない →「比較地点なし」
- c. 境界：差がちょうど 1.0 →「高い」、ちょうど −1.0 →「低い」、0.9 →「ほぼ同じ」
- d. 無害化：伝承内容が `<script>alert(1)</script>` の行の build_popup_html に `<script>` が含まれず `&lt;script&gt;` が含まれる
- e. 欠損：地形分類_状態「データなし」→「データなし」、河川_状態「高さの差 対象外（河川まで1000m超）」→その文字列、参考値→「（参考値）」、標高が NaN →「データなし」。どの場合もポップアップに「nan」を含まない
- f. 移転碑：伝承内容に「移設」がある行は注記を含み、ない行は含まない
- g. 全体：偽データ（碑4基・主な種別3種類・比較地点あり）で main を動かし、output/map_99.html ができる。HTML に全碑の ID、出典の「国土数値情報」、免責文の「相関」、凡例の件数の合計（=4）が含まれ、0基の種別名が凡例に出ない
- h. 入力ファイルが1つ欠けているとき、ファイル名を出して終わる（SystemExit）
- i. （tests/test_summarize.py に追加。M4_review-4 No.1）碑3基の偽データで、碑の値−比較地点の中央値 の差が +、ちょうど 0、− になるようにし、「碑の方が大きい割合」が 0.333 になる（「≧0」で数えると 0.667 になり失敗する）ことを確かめる。既存のテスト関数・偽データは変更せず、新しい関数として追加する
