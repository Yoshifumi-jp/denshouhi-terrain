## 不具合の内容
- 起きていること：update_all.py は update_history_XX.csv の**最後の行**が「完了」でなければ「作り直す（前回が完了していません（…））」にする。一方 run_batch.py の is_completed() は**最後の「完了」の行**の新データのファイルが最新なら「完了済み」とみなして飛ばす。最新データで一度「完了」した県が、その後のやり直し（run_batch --force など）で「失敗」「中断」で終わっていると、update_all は毎回その県を run_batch に渡すが、run_batch は飛ばして終了コード0を返す。県は直らず、次に実行しても同じ判定になる
