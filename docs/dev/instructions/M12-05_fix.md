## 目的（このテーマ1つ）
`python src/run_batch.py --pref "11,37" --force` のように、完了済みの県を --force でやり直そうとすると、すぐ「失敗」になる不具合を直す。

## 不具合の内容
- 起きていること（2026-10-13 17:19 の本番）：埼玉・香川を --force でやり直すと、2県とも数秒で「古いデータと新しいデータが同じファイルです」と表示されて「失敗」になる
- 本来の動き：--force を付けたら、完了済みの県も最初から処理し直して「完了」になる
- 原因の見立て（Claude のソース確認より）：
  - src/run_batch.py は --force のとき「飛ばさない」だけで、update.py を `--pref <県> --no-site` で呼ぶ（199行付近の cmd）
  - src/update.py の determine_old_csv（48行〜）は、前回「完了」の行の「新データのファイル」を古いデータに選ぶ。データの更新がないと新しいデータと同じファイルになり、276〜280行で止まる
  - 本人が手動で `python src/update.py --pref 11 --old= --no-site` を実行すると正しく完了した（`--old=` で古いデータを「なし」にすると全件を処理し直す）
