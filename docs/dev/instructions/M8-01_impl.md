## 3. 判定のルール（関数に分け、それぞれ自動テストを付ける）

### 3-1 画素の位置　lonlat_to_pixel(lon, lat, z=17) → (x, y, i, j)
- fx = (lon + 180) / 360 × 2^z、fy = (1 − ln(tan(緯度ラジアン) + 1 / cos(緯度ラジアン)) / π) / 2 × 2^z
- x = int(fx)、y = int(fy)、i = int((fx − x) × 256)、j = int((fy − y) × 256)（i が横、j が縦。0〜255）
- 既知の答え：(134.584699, 34.066366) → (114536, 52329, 203, 249)／(134.361023, 33.626738) → (114455, 52522, 91, 179)／(133.829332, 33.876322) → (114261, 52413, 197, 104)

### 3-2 1つのレイヤーの色の判定　classify_pixel(rgba, palette) → (区域, 区分, 一致)
- タイルが 404（データなし）→（区域外, 空, 空）
- 透明度 A が 128 未満 →（区域外, 空, 空）。タイルの境界はぼかしてあり、半透明の画素があるため
- A が 128 以上：palette の色と RGB が完全に同じなら（区域内, その区分, 完全一致）。同じ色がなければ、RGB の差の2乗和が最も小さい色の区分を使い（区域内, その区分, 近い色）。差が同じ色が2つ以上あるときは表の上にある方
  - 例：急傾斜地の崩壊で 250,70,0 → 特別警戒区域（指定済）・近い色（実データ 36388-006 で実際に出る色。赤と黄の境界のぼかし）
- 画像は Pillow で開き、RGBA に変換してから画素を読む

### 3-3 土砂災害の3レイヤーのまとめ
- 3つのうち1つでも区域内なら 土砂_状態＝区域内
- 土砂_区分：区域内のレイヤーに特別警戒区域が1つでもあれば「特別警戒区域」、なければ「警戒区域」
- 土砂_現象：区域内のレイヤーの現象の名前を 2-2 の順に「・」でつなぐ（例「土石流・急傾斜地の崩壊」）
- 土砂_指定予定：区域内のレイヤーに「指定予定」の色が1つでもあれば「あり」、なければ空欄
- 土砂_色の一致：区域内のレイヤーがすべて完全一致なら「完全一致」、1つでも近い色なら「近い色」
- 3つのうち1つでも取得不可なら 土砂_状態＝取得不可（区分・現象は空欄）

## 4. タイルの取得とキャッシュ
- 取得の関数は `fetch_func(path, z, x, y)` の形で差し替えられるようにする（src/add_landform.py の fetch_func・sleep_fn と同じ考え方）。戻り値は PNG のバイト列、404 なら None、それ以外の HTTP エラー・通信エラーは例外
- キャッシュ：data/cache/hazard/<キー>/17/<x>/<y>.png。404 は data/cache/hazard/<キー>/17/<x>/<y>.none（空のファイル）を作り、次回は問い合わせない
- 取得不可（例外）のときはキャッシュを作らず、その地点のそのレイヤーを「取得不可」にする。次回の実行で再び問い合わせる
- 問い合わせ1件ごとに sleep_fn（1秒）を呼ぶ（AGENTS.md のとおり）。同じタイルは1回の実行の中でも1回だけ問い合わせる（メモリにも持つ）
- 初回の比較地点の実行は、タイル数によって30分前後かかる見込み。途中で止めても、取得済みのタイルはキャッシュから再開できること

## 5. 出力
### 5-1 data/processed/hazard_36.csv（碑。入力の行の順）、hazard_points_36.csv（比較地点。入力の行の順）
UTF-8（BOM 付き、utf-8-sig）。列：
- ID、碑名、（比較地点のときだけ）元の碑ID、緯度、経度
- 洪水_状態、洪水_浸水深、洪水_色の一致
- 津波_状態、津波_浸水深、津波_色の一致
- 高潮_状態、高潮_浸水深、高潮_色の一致
- 土砂_状態、土砂_区分、土砂_現象、土砂_指定予定、土砂_色の一致
- 近い色の記録（近い色で判定したレイヤーだけ「急傾斜地の崩壊=250,70,0,255」のように「キーではなく現象・災害の名前=R,G,B,A」を全角「；」区切り。なければ空欄）
- 取得日（その行で取得不可が1つもなければ実行日 YYYY-MM-DD、1つでもあれば空欄）
- 状態は「区域内」「区域外」「取得不可」のどれか。区域外・取得不可のとき、浸水深・区分・現象・色の一致は空欄
