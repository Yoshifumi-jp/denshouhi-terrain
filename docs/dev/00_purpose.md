# 目的（第2版）

- 何を作るか：第1版（徳島県）の仕組みを全国（47都道府県、約2,500基）に広げ、全国を一覧できる資料を作る
- 何のために（解決したいこと）：「どんな地形の場所で、どの災害が伝えられているか」を全国規模で確かめ、地域による違いを見られるようにする
- 使う人・使う場面：本人（分析・更新作業）。知人がブラウザで全国ページ・県別の地図・集計結果を閲覧する。印刷して配れる形も用意する
- 範囲（やること）：
  - 全国展開：最新の伝承碑データの再取得・取込、県の指定を複数県・全国に拡張、47都道府県の座標系と隣接県の河川・海岸線への対応、試験県（岩手・長野・兵庫）での通し実行のあと全国を分割実行
  - 全国一覧資料：都道府県の色分け地図、災害種別×地形の全国集計表、年代別推移、絞り込みできる碑の一覧、印刷用PDF、公開
- やらないこと（第2版）：
  - 伝承文に書かれた浸水深・水位の数値化（CR-3 C。第3版以降）
  - 標高の取得方法の変更（1地点ずつ標高APIに問い合わせる第1版の作りを維持し、分割実行で対応する。本人決定 2026-10-05）
  - 伝承碑の写真の利用、災害の発生予測・危険度の判定、国土地理院サイトからの自動ダウンロード（第1版と同じ）
- 使う技術：第1版と同じ（Python 3.10以上、pandas、geopandas、requests、folium、matplotlib 等、VS Code＋Antigravity、Git／GitHub Pages）
