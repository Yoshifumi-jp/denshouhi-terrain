# 目的（第4版）

- 何を作るか：国土地理院の地形分類（人工地形）を、碑と比較地点に付ける（盛土地・埋立地、干拓地、切土地など）
- 何のために（解決したいこと）：今の自然地形だけでは見えない「人の手で変えられた土地」に建つ碑を示す。自然地形と組み合わせて「もとは水部（旧水部）を干拓・埋立した土地」のように読めるようにし、土地の改変で災害の跡が見えにくくなった場所を資料として残す
- 使う人・使う場面：本人（分析・更新作業）。知人が公開ページ（全国ページ・県別ページ・印刷用PDF）で閲覧する
- 範囲（やること）：
  - 地形分類の詳細版で値のある碑・比較地点に、人工地形を付ける（詳細版データなしの地点は人工地形のデータもないため「範囲外」とする）
  - 県別・全国の集計に、人工地形の集計（災害種別×人工地形、自然地形×人工地形）を加える（既存の集計は変えない）
  - 全国ページ・県別ページ・地図・印刷用PDFに人工地形を表示し、注意書きを加える。公開を更新する
- やらないこと（第4版）：
  - 治水地形分類図の追加（画像タイルしかなく色の読み取りが必要。v4_survey.md。第5版以降の候補）
  - ハザード区域外で地形が危険な碑の抽出（改良案5。人工地形の結果を見てから第5版以降で検討）
  - 伝承文に書かれた浸水深・水位の数値化、移設碑の判定の見直し、標高の取得方法の変更（第5版以降の候補）
  - 伝承碑の写真の利用、災害の発生予測・危険度の判定（第2版と同じ）
