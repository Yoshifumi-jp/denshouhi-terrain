# 目的（第3版）

- 何を作るか：地形分類（自然地形）の「データなし」（碑929基・比較地点4,890点、全国の碑の約37%）を、国土地理院の地域版（中分類）・広域版（大分類）で補う
- 何のために（解決したいこと）：詳細版が整備されていない山地・島・地方の碑でも「どんな地形の場所か」を示し、全国の災害種別×地形の比較を偏りなく見られるようにする
- 使う人・使う場面：本人（分析・更新作業）。知人が公開ページ（全国ページ・県別ページ・印刷用PDF）で閲覧する
- 範囲（やること）：
  - 碑・比較地点の全件に地域版の地形分類を付ける（地域版で取れないときだけ広域版）
  - 県別・全国の集計に地域版の集計を加える（詳細版の集計は変えない）
  - 全国ページ・県別ページ・地図・印刷用PDFに地域版を表示し、注意書き（地域版は粗い）を加える。公開を更新する
- やらないこと（第3版）：
  - 伝承文に書かれた浸水深・水位の数値化（本人決定 2026-10-16。第4版以降）
  - 治水地形分類図・人工地形の追加、ハザード区域外で地形が危険な碑の抽出、移設碑の判定の見直し（改良案2・3・5・6。第4版以降）
  - 標高の取得方法の変更、伝承碑の写真の利用、災害の発生予測・危険度の判定（第2版と同じ）
- 使う技術：第2版と同じ（Python、pandas、shapely、matplotlib 等、VS Code＋Antigravity、Git／GitHub Pages）
