# M11 ダウンロード一覧（河川・海岸線）　作成：2026-10-07（Claude）

試験県 岩手(03)・長野(20)・兵庫(28) と、陸で接する隣接県（docs/dev/m10_neighbors.md）の分。
版・年度・容量は国土数値情報のダウンロードページ（2026-10-07 確認）による。利用条件はどちらも「非商用」。

- 河川（W05）：https://nlftp.mlit.go.jp/ksj/gml/datalist/KsjTmplt-W05.html
- 海岸線（C23）：https://nlftp.mlit.go.jp/ksj/gml/datalist/KsjTmplt-C23.html

## 置き場所と展開のしかた（四国4県と同じ）
- zip を右クリック →「すべて展開」。できたフォルダ（例 `W05-07_03_GML`）を丸ごと次へ置く
  - 河川 → `data\raw\rivers\`
  - 海岸線 → `data\raw\coastline\`
- フォルダの中に `…_Stream.shp`（河川）、`…_Coastline.shp`（海岸線）があればよい
- zip ファイル自体は置かなくてよい（置いても動作には影響しない。推測ですが、容量の節約のため削除推奨）
