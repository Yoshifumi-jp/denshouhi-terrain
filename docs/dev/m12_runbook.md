# M12 全国の一括実行 手順書　作成：2026-10-08

M12-02（軽微な整理）の確認が済んでから始める。残り43都道府県・2,033基、見込み約77時間（M11 実測 1基あたり約136秒からの推測）を、8回（1回 おおむね8〜11時間）に分けて実行する。

## 毎回の手順
1. パソコンの電源設定で、スリープを「なし」にする（電源につないでいる場合）
2. VS Code のターミナル（PowerShell）でプロジェクトのフォルダにいることを確かめる
   - **仮想環境（このプロジェクト専用の Python の部屋）を有効にする**：`.\.venv\Scripts\Activate.ps1` を実行し、行の先頭に `(.venv)` が出ることを確かめる。出ていないと `No module named 'pandas'`（pandas がない）で止まる（2026-10-09 に発生。ターミナルを開き直すと毎回必要）
3. 下の表の「コマンド」を1回分だけ貼って実行する
   - **県コードは必ず "…"（半角の二重引用符）で囲む**。囲まないと PowerShell が「03」を数の「3」と解釈して止まる（M11 で発生）
   - 最初に「データの確認」で対象の県がすべて「そろっています」と出ることを見る。「足りません」が出たら止めて Claude に連絡
4. 実行中は、ハザード判定・地形分類でも10件ごとに「進捗 …」の行が出る。数分おきに行が増えていれば正常
5. 終わると「完了 ○県／失敗 ○県／飛ばした ○県」が出る。この画面のスクリーンショットを Claude に送る

## 途中で止めたいとき・止まったとき
- Ctrl+C で止めてよい（M11 で確認済み。その県は batch_log に「中断」と記録される）
- 再開は**同じコマンドをもう一度実行**するだけ。完了済みの県は飛ばし、途中の県はキャッシュ（取得済みのデータ）を使って続きから進む
- 朝までに終わらなかった回は、そのまま止めて翌日に同じコマンドで続けてよい
- 「失敗」が出た県があっても、次の回へ進んでよい（失敗の内容は Claude が batch_log で確認する）

## やらないこと
- 1秒間隔（国土地理院のサーバーへの配慮）を短くしない
- 複数のターミナルで同時に実行しない（キャッシュの書き込みがぶつかるため）
- 徳島（36）は含めない（完了済み。隣接県を加えた作り直しは後でまとめて行う）
