# 目的

- 何を作るか：自然災害伝承碑の1基ごとに地形情報（標高・傾斜・地形分類・最寄り河川と距離・河川との高さの差・海岸からの距離）を付け、災害種別ごとに集計・比較し、地図で見られるようにするシステム
- 何のために（解決したいこと）：過去の災害の記録（伝承碑）と地形の関係を数値で確かめ、「どんな地形の場所で、どの災害が伝えられているか」を知る
- 使う人・使う場面：本人（分析・更新作業）。完成後は知人がブラウザで地図・集計結果を閲覧する
- 範囲（やること）：
  - 第1版：徳島県（71基、2026-09-24時点）を対象に、取込・地形付与・比較地点との比較・地図出力・差分更新・GitHub Pages公開。公開後に伝承内容の分析（災害から建立までの年数、同じ災害の碑群比較）を追加（計画書 版4 M7）
- やらないこと（第1版）：
  - 全国展開・全国一覧資料（第2版で行う）
  - 伝承碑の写真の利用
  - 災害の発生予測・危険度の判定（相関の提示までにとどめる）
  - 国土地理院サイトからの自動ダウンロード（利用規約への同意が必要なため、元データの取得は本人が手動で行う）
- 使う技術：Python 3.10以上（pandas、geopandas、requests、folium、matplotlib 等）、VS Code＋Antigravity、Git／GitHub（無料アカウント、公開リポジトリ）
