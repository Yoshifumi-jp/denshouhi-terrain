# 第3版の候補のデータ調査（着手前）　調査日：2026-10-16（Claude）

## 1. 改良案1：地形分類「データなし」を地域版・広域版で補う

### 入手方法と利用条件
- 今使っているレイヤ `experimental_landformclassification1`（地形分類（自然地形））と**同じURLのまま、ズームレベルを変えるだけ**で取れる（GeoJSON タイル）
  - 詳細版 ZL14〜16（今使っている ZL16。主要な平野部のみ、17種）
  - 地域版 ZL9〜13（全国、中分類12種）／広域版 ZL5〜8（全国、大分類6種）
- 利用条件：国土地理院コンテンツ利用規約（今と同じ。ベクトルタイル提供実験）。データ更新は 2022-03-28（地域版・広域版はこのとき整備）
- 出典：https://www.gsi.go.jp/bousaichiri/lfc_index.html 、https://github.com/gsi-cyberjapan/experimental_landformclassification
- 凡例（style.js から）：地域版 11 山地／12 残丘状地形／13 カルスト地形／21 丘陵・小起伏地／31 火山地形（明瞭）／32 火山地形（やや不明瞭）／33 火山性丘陵／34 火山麓地形／41 台地・段丘／51 低地／61 砂丘／71 湖。広域版 1 山地・丘陵／3 火山地形／4 台地・段丘／5 低地／6 砂丘／7 湖
- 地域版・広域版には、詳細版のような「成り立ち・災害リスク」の解説文はない

### 試しの判定（実データ）
- 「データなし」碑 929基から無作為に60基を ZL13 と ZL8 で判定 → **60基すべて地域版・広域版のどちらでも値が取れた**（重なり複数 0）
  - 内訳（地域版）：低地19・山地18・丘陵・小起伏地9・台地・段丘7・火山麓地形6・火山地形（やや不明瞭）1
- 例：03211-003 山地／42203-016 火山麓地形／05368-001 低地／20202-001 台地・段丘
- 取得量（ZL13）：碑929基で 644タイル、比較地点 4,890点を含めて 1,496タイル（1秒1回で約25分）。ZL12 なら 946タイル

### 決めておくべき扱い（指示書に書く）
- 詳細版の分類（例「氾濫平野」）と地域版の分類（例「低地」）は**細かさが違うので混ぜない**。別の列「地形分類（地域版）」として持ち、詳細版があるところも含め全件に付けるか、データなしだけに付けるかを決める
- 地域版は粗い（推測ですが 1/20万程度）ため、碑とまわりの比較地点（100〜2,000m）が同じ分類になりやすい。比較の読み取りに注意書きが要る

## 2. 浸水深の数値化

### 伝承文（2026-09-24 版・2,481基）を文字で点検した結果（推測を含む粗い数）
- 数値（m・cm・尺・丈）で浸水深・水位・津波の高さを書いた碑：約255基
  - ただし大半は「○○地区で波高14.2m」など**その地域の値**で、碑の場所の値ではない。碑そのものの高さ（「碑の高さ4m25cm」）なども混じる
- 碑の場所の値らしいもの：約58基（例：05202-002「地上から2.56m」、05206-003「海抜6.89m」、24209-002「これより3.0m上が津波水位高」）
- 碑名に「水位」「到達」「浸水」などを含む碑：145基（洪水水位標・津波到達地点など。数値がなくても「ここまで来た」を示す碑）
- 「屋根まで」「床上」「腰まで」など数値でない書き方：約20基（「床上浸水○戸」の件数表現は除く）
- 第2版の計画書の「約120基」は、この調べ方では 58〜255基の間に入る（数え方しだい）

### 見通し
- 自動の拾い出しだけでは「地域の値／碑の場所の値／碑の高さ」を分けきれない。Claude が候補（約370基）を一覧にして3区分の案を付け、本人が目で確かめる作業が必要（推測で2〜3時間）
- 地形と比べる意味が大きいのは「碑の場所の値」（約58基）と「到達地点・水位標の碑」（約145基、重なりあり）
