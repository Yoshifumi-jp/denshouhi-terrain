### viewport の meta が入っているかの確認結果
Folium の出力にはデフォルトで以下の meta タグが挿入されており、スマホ対応として要件を満たしているため追加処理は行いませんでした。
```html
<meta name="viewport" content="width=device-width,
                initial-scale=1.0, maximum-scale=1.0, user-scalable=no" />
```

### 2回実行で HTML が一致したか
Folium が要素のID（例：`map_...`, `popup_...` 等）に乱数（UUID）を用いるため、生成されるHTMLファイルの内容全体の完全一致はしませんでした（差分としてはIDのハッシュ文字列のみ）。碑の件数や出力されるテキスト等の内部データ自体が同一であることを確認しています。
