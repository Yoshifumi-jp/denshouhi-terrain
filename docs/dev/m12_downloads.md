# M12 ダウンロード一覧（河川・海岸線）　作成：2026-10-08（Claude）

全国の残りの分。M11 までに置いた分（河川22県・海岸線13県）は除く。これで河川47都道府県・海岸線39都道府県（海のない8県を除く全部）がそろう。
版・年度・容量は国土数値情報のダウンロードページ（2026-10-08 確認）による。利用条件はどちらも「非商用」。

- 河川（W05）：https://nlftp.mlit.go.jp/ksj/gml/datalist/KsjTmplt-W05.html
- 海岸線（C23）：https://nlftp.mlit.go.jp/ksj/gml/datalist/KsjTmplt-C23.html

- 検算：河川 22県＋今回25県＝47／海岸線 13県＋海のない8県＋今回26県＝47
- 置いてある分は data\raw\rivers・data\raw\coastline のフォルダ名（例 `W05-07_03_GML`）の数字で確かめられる

## 置き場所と展開のしかた（M11 と同じ）
- zip を右クリック →「すべて展開」。できたフォルダ（例 `W05-09_01_GML`）を丸ごと次へ置く
  - 河川 → `data\raw\rivers\`
  - 海岸線 → `data\raw\coastline\`
- フォルダの中に `…_Stream.shp`（河川）、`…_Coastline.shp`（海岸線）があればよい（プログラムは `W05-*_<県コード>_GML/*_Stream.shp` で探す）
- zip ファイル自体は置かなくてよい（推測ですが、容量の節約のため削除推奨）
- 容量の目安：zip 合計 約230MB。展開後は、これまでの実績（zip の約3倍）から推測で約0.7GB。ディスクの空きを1GB以上確保しておく
