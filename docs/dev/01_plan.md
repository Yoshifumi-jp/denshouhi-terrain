# 計画書（第3版）　（版：12　作成日：2026-10-16　状態：承認済み 2026-10-16）

第1版（版1〜10、M1〜M8）は docs/dev/v1/、第2版（版11〜11.8、M9〜M14）は docs/dev/v2/。第3版のマイルストーンは M15 から。

## 目的（要約）
地形分類（自然地形）の詳細版がない碑・比較地点に、地域版（ZL13、中分類12種）・広域版（ZL8、大分類6種）の地形分類を付け、県別・全国の集計と公開ページに加える。

## 設計の基本方針
- **既存の出力は変えない**：地域版は新しいファイル `data/processed/landform_region_XX.csv`（碑）・`landform_region_points_XX.csv`（比較地点）に書く。今の `landform_XX.csv` などの詳細版の結果・集計は変えない（第2版の結果と照合できるようにするため）
- **詳細版と地域版を混ぜない**：細かさが違うため（例：詳細版「氾濫平野・海岸平野」／地域版「低地」）、集計は別の表にする。画面の表示は「詳細版があれば詳細版、なければ地域版（『地域版』と明記）」
- **全件に付ける**：碑と比較地点の比べ方をそろえるため、詳細版がある所も含めて全件に地域版を付ける。地域版で取れないときだけ広域版で補い、どちらで取ったかを列に残す
- 外部への問い合わせは第2版と同じ（1秒以上の間隔、キャッシュ、中断後の再開、10件ごとの進捗表示）。キャッシュは `data/cache/landform/13`・`/8`
- 取得量の見込み：ZL13 で全国 推測3,000〜4,000タイル・1〜2時間（データなしの分だけで1,496タイル・約25分の実測から推計）

## リスク・注意点
- 地域版は粗く、碑とまわりの比較地点（100〜2,000m）が同じ分類になりやすい。「碑の方が低地に多い」などの差が出にくいことを注意書きに書く
- 地域版・広域版には詳細版のような「成り立ち・災害リスク」の解説文がない。ポップアップには分類名だけを出す
- データの更新日は 2022-03-28（地域版・広域版の整備時）。出典の書き方は国土地理院コンテンツ利用規約に従う（今と同じ）
- 島しょ・海際の碑で、地域版・広域版の両方とも取れない場合がある（試しの60基では0件）。M15 のデータ調査で全国の数を見込む
