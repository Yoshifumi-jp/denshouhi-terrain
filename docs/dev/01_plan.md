# 計画書（第4版）　（版：13　作成日：2026-10-18　状態：承認済み 2026-10-18）

第1版（版1〜10、M1〜M8）は docs/dev/v1/、第2版（版11〜11.8、M9〜M14）は docs/dev/v2/、第3版（版12、M15〜M17）は docs/dev/v3/。第4版のマイルストーンは M18 から。

## 目的（要約）
地形分類の詳細版で値のある碑・比較地点に、人工地形（盛土地・埋立地、干拓地、切土地など）を付け、県別・全国の集計と公開ページに加える。自然地形と組み合わせて「もとの地形を人が変えた土地に建つ碑」を読めるようにする。

## データ（v4_survey.md より）
- 配信：https://cyberjapandata.gsi.go.jp/xyz/experimental_landformclassification2/16/{x}/{y}.geojson（ベクトルタイル。今の自然地形と同じ配信元・同じ書き方。実データは ZL14〜16、ZL16 を使う）
- 分類名：今の src/landform_codes.py の対応表を使う（切土地・農耕平坦化地・干拓地・盛土地・埋立地・改変工事中）
- 抜き取り（全国150基）：人工地形の中 21基＝14%（盛土地・埋立地15・干拓地6）。全国の見込み 約350基（推測、220〜500基）
- 人工地形は詳細版と同じ範囲にだけある（詳細版データなしの碑は、徳島11基・抜き取り52基のすべてでタイルなし）

## 設計の基本方針
- **既存の出力は変えない**：人工地形は新しいファイル `data/processed/landform_artificial_XX.csv`（碑）・`landform_artificial_points_XX.csv`（比較地点）に書く。既存の自然地形（詳細版・地域版）・ハザードの結果と集計は変えない
- **状態は4つ**：取得済（人工地形あり）／人工地形なし（詳細版の範囲内で、人工地形のポリゴンの外、またはタイルなし）／範囲外（詳細版データなし。問い合わせしない）／取得不可（通信エラー等）
- **自然地形と混ぜない**：人工地形は自然地形の「上に重なる」情報なので、別の列・別の表にする。画面の表示は「自然地形：旧水部／人工地形：干拓地」のように並べる
- 外部への問い合わせは第3版と同じ（1秒以上の間隔、キャッシュ `data/cache/artificial/16`、中断後の再開、10件ごとの進捗表示）
- 取得量の見込み：詳細版で値のある碑1,552基・比較地点7,505点で ZL16 タイル **7,718枚**（碑だけなら1,409枚）。1枚約1.3秒で **推測 約2.8時間**。何回かに分けて実行できるようにする

## リスク・注意点
- 人工地形は整備時点（土地条件調査の年次。地域で異なる）の状態で、その後の造成・埋立は入っていない。注意書きに書く
- 人工地形があるのは詳細版の範囲（主要な平野部）だけ。山地・島・地方の碑は「範囲外」が多い（全国の碑の約37%）。全国の割合を読むときの注意として書く
- 碑が移設されている場合、碑の場所の人工地形は被災当時の土地を表さない（第2版からのリスクと同じ）
- 実行が約3時間と長い。スリープなし・分けて実行できる仕組みを M19 の条件にする
- データ更新日 2022-03-28（人工地形）。出典の書き方は国土地理院コンテンツ利用規約に従う（今と同じ）
- 第2版・第3版のリスク（碑の位置＝被災地点とは限らない、ハザードの想定年次が県で異なる、移転碑の誤検出、公開リポジトリでは docs/dev も見られる）は引き続き有効
