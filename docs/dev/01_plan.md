# 計画書　（版：10　作成日：2026-09-27　状態：承認済み 2026-10-04（版10））

## 目的（要約）
自然災害伝承碑（国土地理院、2026-09-24時点）の徳島県分71基に、標高・傾斜・地形分類・河川や海岸との位置関係を付け、
災害種別ごとに「碑のない比較地点」と比べて集計し、地図で閲覧・公開できるようにする。
県を設定で切り替えられる作りにし、第2版で全国展開（2,481基）と全国一覧資料の作成につなげる。

## 設計の基本方針（全マイルストーン共通）
- 対象県は設定で切り替える（県コード：徳島=36、千葉=12）
- 結果は碑の ID をキーに保存し、外部への問い合わせ結果はキャッシュ（保存）して再利用する
- 元データ（data/raw/）は読むだけ。取得は本人が国土地理院サイトで規約に同意して手動ダウンロード
- 外部サーバーへの問い合わせは1秒以上の間隔を空け、中断しても続きから再開できるようにする
- 計算部分（件数の集計、距離・傾斜・高さの差、差分判定など）には自動テスト（pytest）を付け、答えの分かっている例で結果を照合する。テストはネットに接続しなくても動くようにする

## リスク・注意点
- 地形分類データは全国一律ではなく、地域によって「データなし」が出る可能性がある。M3着手前にClaudeが入手方法と範囲を確認し、必要なら計画を改訂する
- 河川（国土数値情報）・行政区域・海岸線のデータは本人の手動ダウンロードが必要になる見込み。データごとに利用条件と出典の書き方が異なる
- 比較地点を県全体から無作為に選ぶと山地が多くなり、碑（集落の近くに多い）との差が地形ではなく「人が住む場所かどうか」を表してしまうおそれがある。→ 版6で「各碑の周辺（100m〜2,000m）」から選ぶことに決定（2026-10-02）。比較結果は「碑はまわりより高い／低い場所にあるか」を表す
- CR-2・CR-3 D は 2026-10-03 に決定（版7）：CR-2 は M8 として追加、CR-3 D は取り下げ（変更履歴を参照）
- ハザードマップ（M8）の想定区域は国・県が公表した「想定」であり、本プロジェクトが危険度を判定するものではない。表示・集計では「想定区域との重なり」と書く。データの年次・取得日を併記する。M8 はハザードマップポータルの配信タイルを使う（版8）。徳島県は2025年9月に新しい津波浸水想定を公表したが、配信タイルは旧想定（平成24年）のままとみられる（タイルの更新日が2023年。推測を含む）ため、公開ページにその旨を書く
- 「伝承の空白地帯」（碑のある場所と地形が似ているのに碑がない地区）の抽出は、「危険度の判定はしない」に抵触しやすいため行わない（CR-3 検討時に見送り）
- 碑の位置＝被災地点とは限らない／登録は市町村の申請によるもので網羅的ではない。結果は「相関」として表示する
- 伝承碑の写真は使わない（二次利用に申請が必要な碑がある）
- GitHub の公開リポジトリでは、docs/dev/ の開発資料も含めて誰でも見られる。コミットに記録されるメールアドレスは GitHub の非公開用アドレス（noreply）を使う
- 国土地理院の標高データ等のうち基本測量成果の複製・配布に当たるものは、測量法上の申請が必要な場合がある。公開前（M6）に確認する
