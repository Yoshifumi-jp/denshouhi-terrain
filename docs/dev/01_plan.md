# 計画書（第2版）　（版：11.6　作成日：2026-10-05　状態：承認済み 2026-10-05、版11.3 は本人の変更要求 2026-10-08、版11.5 は本人決定 2026-10-13、版11.6 は本人承認 2026-10-14）

第1版（版1〜10、M1〜M8）は docs/dev/v1/01_plan_v1.md。第2版のマイルストーンは M9 から番号を続ける。

## 目的（要約）
第1版（徳島県71基）の地形付与・比較地点・ハザード判定・伝承内容の分析・地図を全国（約2,500基）に広げる。
処理は県ごとに行い（第1版と同じ作り）、全国の結果はそれを束ねて作る。束ねた結果から全国一覧資料（色分け地図・集計表・年代別推移・碑の一覧・印刷用PDF）を作り、公開する。

## 設計の基本方針（第1版の方針に追加）
- 処理の単位は県のまま。県ごとの出力（*_{県コード}.csv）を変えず、全国の資料はそれらを読んで束ねる。こうすることで第1版の徳島の結果が変わらないこと（ハッシュ3件の一致）を毎回確かめられる
- 外部への問い合わせは第1版と同じ（1秒以上の間隔、キャッシュ、中断後の再開）。全国では合計約25万回・約70時間の見込み（徳島71基で約7,300回からの推計。推測を含む）のため、県ごと・数県ずつ分けて実行する
- 県の境に近い碑のために、河川・海岸線は「対象県＋陸で接する隣接県」のデータを読む
- 第1版の未対応箇所（座標系の登録が徳島・千葉のみ、など）は、全国を回す前に M9・M10 で直す

## 第3版以降（今回の範囲外・予定）
- 伝承文に書かれた浸水深・水位の数値化（全国約120基に記述あり）（CR-3 C）
- 標高の取得を標高タイル方式に変えて処理時間を短くする（第2版では見送り。M11 の実測で所要時間が見込みを大きく超える場合は、計画の見直しとして本人に相談する）
- 先々の検討候補（2026-10-12 本人依頼で記録。国土地理院の資料館展示「治水地形分類図」「地形分類（自然地形）」「地形分類図と自然災害伝承碑から災害リスクを考える」から。着手時は必ずデータ調査から始める）
  1. 地形分類の「データなし」を減らす：詳細版（ズーム16で取得、主要な平野部のみ整備）がない場所を、中分類の「地域版」・大分類の「広域版」で補う。M12 の実績で碑の「データなし」は和歌山36%・島根39%・山口68%。配信の形式・ズームは未確認
  2. 治水地形分類図（旧河道・後背湿地・自然堤防など）の追加：洪水の碑との関係を見るのに向く。配信の有無・利用条件は未確認
  3. 地形分類（人工地形）の追加：盛土・埋立地など。地震・液状化の碑の分析を補う
  4. 全国一覧資料で「災害種別×地形分類」の集計を主軸にし、比較地点と比べて偶然かどうかを見る（第2版の全国一覧の作り方しだいで、一部は第2版で扱えるか検討）
  5. 「ハザード区域外だが、地形は危険（旧河道・後背湿地・埋立地など）」の碑を抜き出す
  6. 集計では移設された碑（relocated）を分けて扱う（今の場所の地形が被災地の地形と一致しないため）
  注意：地形分類は一般的な傾向であり個別の場所のリスクを示すものではない（地理院地図の注記）。境界は1/25,000相当の精度

## リスク・注意点
- 実行時間：約70時間（推測）→ M11 実測（2026-10-08）：試験3県377基で14時間13分（1基あたり約136秒。1基あたり標高63回・ハザードタイル34枚・地形分類5枚）。残り43都道府県2,033基で約77時間の見込み（推測）。パソコンのスリープ・再起動で止まるため、一括実行は中断後の再開を前提にする。国土地理院のサーバーに負担をかけないよう、1秒間隔は短くしない
- 河川・海岸線データのダウンロード：試験県3県だけでも隣接県を含めると十数県分が必要（岩手の隣：青森・秋田・宮城、長野の隣：新潟・富山・岐阜・山梨・埼玉・群馬・静岡・愛知、兵庫の隣：京都・大阪・岡山・鳥取）。M11 の前に Claude が県ごとのダウンロード一覧を作る。全国では推測で合計500MB前後。data/raw/ は Git 対象外
- 河川データ（W05）は県ごとに整備年度が異なる可能性がある。年度の違いは M12 の点検で一覧にする
- 地形分類（自然地形）は全国一律に整備されていない。「データなし」の県・碑が増える見込み。結果の表示で「データなし」の割合を併記する
- ハザードマップの配信タイルは県によって想定の年次が異なる（徳島の津波は旧想定のまま、など）。全国ページの注意書きに「県によって想定の年次が異なる」旨を書く
- 伝承碑データは国土地理院が随時追加している。M9 で再取得したデータを第2版の基準とし、その後の追加は M14 の更新コマンドで反映する
- 座標系：島しょ部（小笠原・南西諸島など）で県の代表の系を使うと距離が大きくずれる。M10 で碑の位置による選択を必須とする
- 全国の地図・一覧のファイルが大きくなり、スマホで開くのが遅くなるおそれ。M14 で容量を確かめる
- 第1版のリスク（碑の位置＝被災地点とは限らない、登録は網羅的でない、写真は使わない、海岸線データは非商用に限る、公開リポジトリでは docs/dev も見られる）は引き続き有効
