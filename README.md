# denshouhi-terrain（自然災害伝承碑×地形 分析システム）

国土地理院の「自然災害伝承碑」データに、碑ごとの地形情報（標高・傾斜・地形分類・河川や海岸からの距離）を付け、
災害種別ごとに「碑はどんな地形に立っているか」を集計・地図化する個人開発プロジェクトです。

- 試験地：徳島県（第1版）。全国展開は第2版で行う予定
- 状態：開発準備中（進行状況は docs/dev/status.md）

## フォルダ構成
| フォルダ | 内容 |
|---|---|
| data/raw/<取得日>/ | 国土地理院からダウンロードした元データ（手を加えない） |
| data/processed/ | 整形・地形付与後のデータ |
| data/cache/ | API取得結果の保存（再作成可、Git対象外） |
| src/ | プログラム |
| output/ | 地図・集計表・グラフ |
| docs/dev/ | 開発管理資料（計画書・指示書・確認記録） |

## 出典・注意
- 自然災害伝承碑データ：国土地理院（https://www.gsi.go.jp/bousaichiri/denshouhi.html）を加工して作成
- 本システムの分析結果は地形との「相関」を示すもので、災害の発生を予測・保証するものではありません。
  防災上の判断には自治体のハザードマップを使ってください。
